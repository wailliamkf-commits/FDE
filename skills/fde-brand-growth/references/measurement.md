# 数据与指标契约

## 来源与粒度先于计算

每份输入记录 source_id、文件/报告位置、导出时间、起止日期、时区、币种、账户、筛选、粒度、转化动作、归因模型/窗口、日期归属、覆盖和延迟。CSV/Excel读取全部相关子表，嵌图与文字另列来源；OCR关键金额人工/原图核对。周表与月表重叠时选一个基准，保留对账差额，禁止强行配平。

原始事实表分别保存：广告日/系列/搜索词、站内会话/事件、订单/退款、商机/报价/合同、商品/变体/库存、页面/资产版本。用账户+平台ID识别广告对象，用商店+商品/变体ID识别商品；映射表记录有效期和一对多关系。聚合到相同粒度再连接，检查连接前后行数、费用与收入是否膨胀。

两广告平台认领同一订单时，平台归因收入分开展示；经营收入来自订单事实一次去重。跨设备身份不明标未知。Google Ads点击与Shopify/GA4会话不等价，只能对账差异，不能相除成为“真实流失率”。不同来源ATC、Checkout、Purchase不能直接串成真实用户漏斗。统一漏斗须具备同一身份、事件顺序、观察窗口和去重规则；否则标题写「事件量对照」。

## 证据状态

- OBSERVED：原始数据可追溯，记录覆盖与局限；并不自动证明因果。
- REPORTED：历史对话、会议或人工汇报；在当前数据复核前不升级为已验证。
- HYPOTHESIS：可证伪的解释，附替代解释和验证计划。
- UNKNOWN：缺失；不得转换为0、均值或“无问题”。
- SYNTHETIC：手工演示或测试数据；不进入真实业绩和决策依据。

## 核心指标

所有率先合计同口径分子分母，再计算；不平均各行比率。分母为0返回不可计算。利润与增量收入可以为负；计数和普通费用不能用负数掩盖冲销，冲销单列。

| 指标 | 分子 / 分母或定义 | 解释边界 |
|---|---|---|
| 有效访问量 | 排除已识别机器人、内部测试后的会话数 | 排除规则与覆盖可追溯，不代表购买意图 |
| 匹配访问率 | 满足预先定义的人群/需求/承诺规则的会话 / 可评价有效会话 | 意图不可判断列 unknown；规则不得用“最终购买了”定义，否则循环论证 |
| 匹配覆盖率 | 可评价意图的会话 / 有效会话 | 高匹配率可能来自只观测一小部分 |
| 合格行为率 | 发生类目所需选型/商品/报价行为的去重会话 / 有效会话 | GA4 engaged session只是平台定义，不能直接改名合格流量 |
| 购买会话率 | 含有效购买的会话 / 同组有效会话 | 不以订单数代替购买会话数；事件顺序另核 |
| 加购/结账完成率 | 同组按顺序完成后一步的人/会话 / 有资格进入该步的人/会话 | 全程保持同一个统计单位和窗口 |
| 归因ROAS | 指定平台、动作与口径的购买归因价值 / 对应费用 | 分数归因次数不是去重订单；不与ATC价值相加 |
| 经营营销效率 | 财务口径净收入 / 同期明确范围的营销费用 | 描述整体结果，不证明该费用带来所有收入；明确是否含人员/素材 |
| 新客CAC | 分配给该获客范围的完整营销费用 / 去重首次付费客户 | 新访客≠新客户；归因CAC不自动是增量CAC |
| 订单贡献（营销前） | 扣折扣/退款/代收税后的净收入 − 货品、履约、支付、退货处理、其他变动服务成本 | 收入是否已扣退款须声明，避免重复扣；固定费用另列 |
| 营销后贡献 | 营销前贡献 − 对应范围营销费用 | 财务映射确认后再判盈利 |
| 可承受CAC | 约定回本窗口内保守的新客预期贡献 − 目标剩余贡献/风险准备 | 未验证LTV不能资助当前超额投放 |
| 边际CAC | Δ可比获客费用 / Δ新客 | Δ新客≤0不可算有效正回报；非实验差值仅方向性 |
| 增量CAC/ROAS | 与设计匹配的增量费用 / 增量客户；增量收入 / 与设计匹配的增量费用 | 冻结对照、规模校正和成本边界；零投放对照可用相关实验投放费，非零基线扩量用相对对照的费用增量；增量费用≤0另作节支分析 |
| 合格商机率 | 满足预设服务范围、项目、预算/需求与时点条件的商机 / 有效线索 | 与询盘-报价-成交率分开；跟随成交周期 |
| 回本周期 | 累计成熟贡献首次覆盖获取费用的时间 | 未回本写未回本/观察不足，不外推承诺 |

## 防止错误的“品牌资产流量总和”

一个会话只能有一个会话来源渠道。`repeat/new_customer` 是人群属性，品牌词是查询属性；自然搜索含品牌自然搜索，彼此不是可直接相加的独立渠道。

采用三个并列面板：
1. 来源面板：互斥渠道份额和 unknown/direct 单列；总和对账100%，Direct不推定为品牌忠诚。
2. 客户面板：同源订单的新老客、回访、复购/推荐/项目续单及贡献。
3. 资产面板：具体页面/内容/客户关系的使用、维护成本和关联成熟商业结果。

只有定义互斥会话集合、去重和unknown覆盖后，才可额外报「指定非付费来源会话占比」；名称不写“已证明品牌资产贡献”。非付费渠道仍有内容和运营成本。

## 数据获取清单

| 决策 | 平台报告/对象（名称，路径须当时核验） | 必要字段与条件 |
|---|---|---|
| 流量与花费结构 | Google Ads/Meta 系列报告 | 两账户分开；费用、展示、点击、购买动作和价值、日期、归因设置；历史暂停系列保留 |
| 意图 | Google Ads搜索字词与搜索关键词分别导出；Search Console查询 | 查询/关键词/匹配类型、系列、费用、点击、购买；GSC点击不作广告费用证据；隐藏查询覆盖单列 |
| 页面承接 | Ads着陆页；GA4/Shopify会话与页面报告 | 实际URL、来源/媒介、设备/地区、会话、行为、购买；统一日期与页面映射 |
| 展示机会 | Search竞争指标与竞价分析 | 展示份额、预算/排名损失、竞品重叠/上方率；分系列，不把对手份额当抢走的订单 |
| 商品与供给 | 广告产品报告；商品/变体、订单、库存 | 商品ID、费用、购买价值、真实净收入、成本、可售/交期；核查排除和拒登的区别 |
| 结账与线索 | Shopify弃单/支付事件；CRM线索/报价/合同 | 脱敏ID、时间、失败类别、金额、处理进度；无支付事件不猜支付根因 |
| 长期资产 | Search Console、内容清单、CRM、订单 | 资产ID/版本、主题、来源、维护投入、使用与商业结果、成熟窗口 |

补数单写确切区间、账户、报告、字段、筛选和用途，能用去标识聚合数据解决时不索取联系资料。

官方定义核验：见 [来源](sources.md)。

## 增量成本示例（合成）

同等规模实验组费用1200、对照费用1000，经设计校正后的增量收入600：用于评价加码的增量费用是200，增量收入/增量费用为3。600/1200=0.5回答的是另一个成本范围，不能混标为同一指标。人群规模不同必须先按实验方案校正；收入差值、费用差值本身不证明因果。人员/素材成本是否包含在分母需随指标名称说明并保持两组一致。

## 快照与季节覆盖

进行中窗口、累计快照差值、回补与退款队列处理，见 [监控反馈](monitoring-feedback.md)。记录表实际覆盖而非上传者描述的覆盖；重复月份不作独立证据。事件序列与归因事件量保持分开。

## 来源链与会议资料

保留原始来源ID、引用位置、采集时间、覆盖与派生关系。录音、转写、摘要及引用该摘要的对话属于同一证据族，不累加独立样本。未核实的转写表述标REPORTED，听不清/说话人不明保留不确定；会议决定不等于执行，执行记录不等于业务效果。原件留在项目工作区，仓库只保留抽象方法。
