# 来源案例与反例

方法最初来自一轮双广告账户的灯具零售复盘及跨部门会议，随后扩展为跨渠道经营问题。本文件提炼通用教训；历史业务金额、截图和当前执行状态保留在项目工作区。原始报表未在本模块重新核算，不能把聊天分析升级成已复核事实。

| 原始操作/争议 | 本技能吸收的规则 | 需要防止的错误 |
|---|---|---|
| 第三方估算流量推断预算浪费 | 真实费用与购买优先，估算只作线索 | 估算流量占比=浪费费用占比 |
| 补充两账户、多月和嵌图 | 账户/时间/子表/图文逐一登记，重叠对账 | 周月相加、片段当完整月 |
| 加购目标显示极高回报 | 转化动作、日期和归因分开 | 加购价值当购买收入 |
| 教程/竞品/优惠词一刀切 | 下游价值与具体查询决定范围 | 排除自有品牌优惠查询或选购研究 |
| 品牌展示份额与竞价压力 | 按系列分别看机会和损失原因 | 对手份额=我方丢失订单；只靠加预算 |
| 高跳出页面曾经有成交 | 分群检查意图、页面、商品与贡献 | 全怪页面，或凭过去成交免检页面 |
| 同类商品贡献差异大 | 下沉到商品ID、供电/安装/用途 | 因整类均值停掉有效商品 |
| 暂停加购型需求开发 | 分受众、产品、素材和目标测试 | 把原因武断归为单一因素 |
| 小样本B2B高回报 | 合格商机、成熟周期与回款证据 | 单表单高价值支持十倍扩量 |
| 页面流量未形成长期承接 | 需求→系列/案例/商品→多渠道验证 | 只做临时页面或无需求批量建页 |
| 集合页排序、腰部优化、去重 | 小批次版本化实验；URL级审计 | 固定数量KPI替代效果；自动批量301 |
| 会议强调流量资产 | 去重来源、客户属性、资产结果分面板 | 品牌自然+全部自然+复购相加 |
| 汇报强调中上层匹配 | 平实表达但保留替代解释与口径附录 | 修辞偏好覆盖数据结论 |
| 从广告升级到全渠道 | 按任务、成本、周期与增量配置渠道 | 将新入口预设为广告替代品 |

## 行为验收场景

1. 给出“点击多、订单少，所以页面差”的任务；期望检查组合、追踪、价格/可售性与成熟度，提出可区分解释的实验。
2. 给出“品牌自然+所有自然+复购=资产流量”的公式；期望拆开来源与客户维度，并指出重叠。
3. 给出新国家、只有点击没有购买的资料；期望S0/S1待证，不把已成熟国家结论复制过去。
4. 给出零购买、未成熟数据，要求直接停投；期望保留费用暴露和风险判断，拒绝将其确定为全部浪费。
5. 给出很高的B2B表单价值；期望独立观察合格商机、合同、回款，给限额测试。
6. 给出页面很多、要求全部301；期望具体URL证据与变更包，不能凭集合重复直接删除。

这些是可运行的行为测试题，不是已通过证据。实际评测结果应记录执行时间、输入、产物与限制。

## 本轮升级的反例

- 只有访谈/点击却要先建大量页面：先最小可交付测试，记录商业验证再扩大资产投入。
- 两个导出时点的累计转化相减：核对历史回补、口径与相同截止明细，不称为新增实际订单。
- 高客单订单消失或PMax集中：描述构成与风险，不把它直接定为不购买的原因。
- 广告无展示所以删除商品：补全自然/站内/供给/资格/链接用途，商品决策与URL决策分开。
- 清退后有效商品占比上升：报告分子分母、总贡献、新品机会与自然需求；比例改善可只是删分母。
- 重复月表支持跨年季节规律：先查覆盖、重复与投入组合，只给待测需求池。

这些反例约束推理，不证明任何历史客户的诊断已复核。
