# 广告、SEO、网站与销售协同

适用触发：搜索需求未被承接、广告承诺与页面不符、页面更改影响渠道、定制商机流失，或跨部门等待错过机会。沿用demand_id和 [研究到行动工作表](../assets/research-to-action.md)，不要求每次运行全部分支。

## 双向需求交接

广告提供查询/素材、受众、费用与成熟转化；SEO提供可见查询、落地页与内容缺口；客服/销售提供疑问和失单。记录日期、地区、设备、品牌/非品牌、查询覆盖及证据状态。三者可以验证同一需求，不能把广告投入解释为自然排名购买或未来“返还”。

每条需求先匹配现有页面：补清事实或FAQ、增加选型/案例，还是确有独立意图需要新页面？未核实的问题留在内部待答清单；公开答案须有商品/服务事实支持。采用AI辅助也需核验原创价值与准确性，内容长度按用户任务决定，不承诺靠篇数带来排名。自然内容发现有效需求也可反向形成小范围广告试验。

交接必须包含查询/问题来源、意图、适用商品与限制、页面版本、负责人、验收和复核时间。分别观察索引/可见性、相关点击、行为、成熟商业结果；曝光或被收录只证明前段。抓取、索引与可见性的观察窗口依据站点状态及实际发现进度设置；购买、退款或商机的成熟窗口另外按商业周期设置。短购买周期不能用于断言SEO已见效或失败，不承诺两周见效。跨渠道调整同时记录总投入、去重结果与贡献；暂停一个渠道后另一渠道归因增长不能证明前者无价值。

## 承诺连续性与移动端承接

按真实主要设备和市场抽样走完整链路：广告/搜索摘要 → 实际URL → 首屏和相应商品 → 选择变体/询盘 → 结账/提交 → 确认及接收。核对广告展示的商品、场景、价格、优惠条件、库存与交期是否容易找到并一致。页面截图不能替代提交成功或销售接收证据；测试使用明确的测试身份和获授权的环境。

上线前检查：优惠实际有效期、适用SKU/地区、领取或自动应用条件、结账金额、参考价依据、叠加限制、到期撤除负责人。长期优惠不自动违规，但不能用虚假的限时、基准价或不可兑现承诺制造紧迫。旧活动页与首页横幅同时纳入检查。

移动端按任务判断：首屏信息、触控与阅读、变体操作、表单输入、错误提示和付款/询盘闭环。不要硬编码“90%手机”“必须三次点击”或所有内容折叠。减少选择困难与不必要步骤，保留关键规格、限制和信任事实。正常可展开内容与仅为操纵搜索而隐藏内容区别对待。

页面改版先做渠道影响清单：活跃广告URL、Feed链接、自然入口、追踪和事件。保存旧版本与回退方式；实施和发布由对应站点流程验收，不能默默删除正在承接需求的页面。

## 定制与项目销售

先区分即买零售与咨询/报价路径；只采集决定可服务性所需字段，例如用途、尺寸/数量、目的地、时间、预算范围及必要联系方式。按适用法律和项目规则处理个人资料，不收集无用途字段。

最小流程：收到 → 去重及确认需求 → 合格/不适配及原因 → 报价 → 跟进 → 成交/失单 → 履约/回款。每步有责任人、时间戳、约定时效及超时处理。按同一成熟队列看合格率、首次响应时间、报价率、成交、贡献与流失原因；提交表单不等于合格商机。

先用可追踪的人工流程验证需求与处理能力；只有明确数量、等待或权限问题，才评估CRM集成、登录门户、配置器。隐藏页面或要求登录不等于拥有产品/图片/设计权利；来源与权利不清的内容标HOLD并交相应责任人核实，不提供规避投诉的实施方式。

## 组织速度也是增长约束

记录发现需求、确认供应、内容就绪、技术就绪、验收上线、首次合格结果的时间。用“交接被接收至下步开始”的等待时间区分排队与制作耗时；同时记录返工原因和机会窗口。增长负责人排优先级，各环节明确接收人、完成条件与升级路径。时效由团队容量与需求窗口约定，不强加统一天数。

监控不仅看流量：活动到期未撤、链接/追踪损坏、承诺不一致、询盘无人接收、供应事实过期需要明确责任与修复顺序。与 [监控反馈](monitoring-feedback.md) 共用事件和复盘，避免另建一套账本。

## 域名与平台是经营选择

域名改动先审计已有入口、品牌识别、URL、语言/地区、链接与追踪。新域名、双站或迁移都要说明解决的问题及维护成本，不把某后缀、老域名、同IP推断成必然排名结果。迁移需要URL映射、正确重定向、监控与恢复预案；DNS调整不等于逐页重定向。品牌保护核实真实权属和用户混淆证据，不采用冒充竞品或误导导流。

平台渠道试验同时计入佣金、履约、退货、库存占用、运营成本及自站替代效应。平台销量与平台可用客户关系单独记录，不能自动记为自有站品牌资产；退货成熟后再比较增量贡献。

## 机制核验来源

以下为2026-09-18核验的官方机制说明；具体项目需按实施时最新规则复核，不代表本次已验证业务效果。

- [Google：是否需要SEO](https://developers.google.com/search/docs/fundamentals/do-i-need-seo)：广告不改变自然搜索排名。
- [Google：有用内容](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)：面向用户并提供实际价值，没有统一首选字数。
- [Google：垃圾内容政策](https://developers.google.com/search/docs/essentials/spam-policies)：区分规模化操纵、隐藏内容滥用与正常用户体验设计。
- [Google：更改URL的站点迁移](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes)：迁移规划、映射和波动监控。
- [Merchant Center：虚假陈述](https://support.google.com/merchants/answer/12079606?hl=en)：价格、可用性和优惠承诺须真实。
- [USPTO：设计专利基础](https://www.uspto.gov/patents/basics/apply/design-patent)：产品外观可能涉及权利；具体国家和产品需另行核实，不能从转写断言某类商品无权利限制。
