# 多语言变更控制

用于翻译修订、术语统一和分语言批量修改。采用`preflight→baseline→scan→sweep→terms→apply→review→signoff`阶段链；输入、回执和失败队列均留在项目内。它是人工/执行器可遵循的方法，没有隐含批量写入程序。

## 输入、状态与批次

输入：稳定page_id/URL全集、目标语言及地区变体、源语言版本、可编辑字段、URL变更权限、术语/品牌保留规则、平台读写能力、预览环境、资源上限和复核人。明确单位：页面、唯一字符串、字段、片段和请求各自计数，去重字符串仍须回查不同页面的语境。

每条工作项以`locale × page_id × field × segment_id`定位，附source_digest、input_digest、terms_version、before/after、finding_id、patch_id、状态和回执；同时有批次ID、预计项数、已读取/已修改/已验证/失败/未触达项数。所有目标项恰有一个终态或待办状态，不能用“完成率”掩盖漏片。

建议状态：PENDING / READY / APPLIED / VERIFIED / BLOCKED / STALE / TERMS_STALE / NOT_APPLICABLE。回执记录阶段、输入版本、输出摘要、实际对象、证据、时间和真实执行/复核主体。工具超时记UNKNOWN_RESULT，先读回再决定是否重试；摘要变化不是翻译质量证明。

## 阶段操作与完成条件

| 阶段 | 操作 | 产物与完成条件 |
|---|---|---|
| preflight | 确认语言地区、编码、RTL、页面/字段集合、读写权限、翻译额度真实口径、测试环境和回退；试读代表页 | 范围与通道已核实；权限/额度UNKNOWN只阻止相应写入，不假定夸大显示数是真实预算 |
| baseline | 导出源与目标字段、路由/URL集合、必要canonical/hreflang及图片链接，记录版本/摘要；确认能恢复 | 基线清单和回退可读取；来源变动后重新冻结受影响范围 |
| scan | 全量扫描约定集合中的乱码、占位符、语言污染、未翻标题/字段、英文残留、术语差异与破损链接 | 每项缺陷有定位、原文、类别和严重性；扫描失败/未读项入队，规则命中是候选 |
| sweep | 人工或规则辅助逐类确认机器硬错，建立最小修复候选；误报按品牌名、代码、单位等原因登记 | 不会把合法保留词当污染；缺译/断片/错误编码先处理，未确定语义留BLOCKED |
| terms | 定义固定保留、固定翻译、按语境处理三类词；明确地区变体、单位、称谓与RTL约定 | 有版本的术语表及语境例外；使用项目选择，不能把es-ES/pt-PT等案例语言强加所有站 |
| apply | 先做含关键缺陷与布局的代表小批，再按语言×缺陷×页面扩展；逐项检查源摘要/术语版本/前置值，仅写允许字段 | 实际补丁、保存读回及回执齐全；输入漂移项记STALE，未授权URL改动拒绝应用 |
| review | 重扫已改项及相关页面，比较URL集合和字段差异；人工审查关键唯一字符串及其页面语境，验证RTL/移动布局、表单和媒体请求 | 每项修复有关闭证据；负面回归、缺回执、误译和未触达项仍开放，样本质量与全量覆盖分列 |
| signoff | 核对范围分母、补丁回执、未决/例外、语言复核和目标环境运行证据；由实际责任人签署具体范围 | 形成可审阅签字材料；未取得签字就记SIGNOFF_PENDING，不由Agent代填授权 |

## 质量门与批量节奏

先按风险确定代表批：短文本/长文本、标题/正文/表单、RTL或特殊字符、含术语/数字/链接的内容。尺寸、批量和抽样比例由资源与失败影响确定，填写在[SEO发布矩阵](../assets/seo-release-matrix.md)，不继承案例吞吐或得分。

机器门：约定范围可解析、所需片段齐全、确认的乱码/占位符/错语言/缺译等阻断缺陷为零。合法原文保留词逐项登记例外，零正则命中不是母语质量证明。

人工门：关键承诺、价格/费用、规格、CTA、政策与表单错误文字按适用范围审校；共用字符串检查语境，不能只验术语表。普通内容抽样须记录抽样方法、页面/字符串分母、语言覆盖、缺陷率计算口径及未审范围。没有合适语言复核人，就交机器修复与待审队列，不声称母语级。

运行门：冻结URL集合无未登记变化；允许的URL变更单独走[URL变更流程](seo-delivery-playbook.md)。实际检查目标语言入口、切换、canonical/hreflang适用项、RTL与移动布局、表单提示及媒体请求。仅后台字符串完成不算前台完成。

批次通过代表范围的保存、读回和review后才扩展；明确发生误改、意外URL变化、关键误译或无法恢复时停止新批次，回退受影响项并定位原因。收尾分别给出“可公开运行范围”和“语言验收范围”，不能合成全站通过。

## 中断、术语变更与失败回退

1. 每批保存最后完成阶段、输入/术语版本、已提交但未确认项、失败队列和下一项。恢复先读当前目标与回执：已核实项跳过，未知结果先对账，STALE项重建。
2. 术语改变时按引用关系标记受影响项TERMS_STALE，从terms/apply/review重跑；没有可靠依赖关系就扩大受影响范围重新检查，不能凭旧回执放行。
3. API拒绝或权限不足时，继续导出、扫描、草稿和人工导入清单；平台原生编辑器仅在已有写权限范围内替代。改变服务商或把私有文案发给新目的地须符合现有授权。
4. 超时/限额先保存进度并查实际提交，按服务端指引退避或缩小批次；同条件两次失败后不继续盲重试。预算显示未知时保留UNKNOWN，明确等待/人工处理范围。
5. 回滚定位到page_id/字段/前置版本，避免覆盖同期合法编辑；回滚后重扫并回读对应语言前台，不能将“撤销按钮已点”当恢复成功。

输出：版本化基线、缺陷队列、术语表、补丁/回执、覆盖对账、人工复核及签字状态。来源线索为new-video-006/015/020的视觉记录；其中抽样分、行吞吐与作者完成自述都不构成全站上线或质量证据。
