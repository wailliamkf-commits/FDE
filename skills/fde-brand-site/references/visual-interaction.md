# 品牌视觉、响应式与动态体验

## 1. 视觉不是产品图数量

先给品牌定义可辨识的画面规则：色彩角色（背景/文字/强调/错误）、标题/正文/导航字体及授权、空间尺度、边框/圆角、摄影光线和材质、人物关系、图注与概念标记。选一套主方向，必要时比较少量差异明显的候选；不是同时混合几个竞品皮肤。

| 图像角色 | 要回答的问题 | 适合位置 | 可信度边界 |
|---|---|---|---|
| 品牌主视觉 | 我属于这个世界吗 | 首页/专题入口 | 原创生活场景可为概念，不冒充用户/明星代言 |
| 使用/人物场景 | 在什么时刻、怎样使用 | 首页意义、系列/详情辅助 | 不伪造使用效果或真实客户证言 |
| 产品身份 | 实际形状/材质/结构是什么 | 列表/详情 | 实物与渲染区分；不可修成不存在的规格 |
| 细节/比较/比例 | 哪个选项更适合 | 详情、比较、指南 | 同比例/光线/视角；无法精确就标示意 |
| 品牌理念 | 观点如何落到行为 | Story、设计方法 | 文字可编辑，不把通用静物称作生产证据 |
| 工艺/证书/质检 | 为什么相信 | 详情、Process、信任模块 | 只能用真实授权资料；生成证书、假工坊、假检测禁用 |
| 信息图/流程 | 哪些选择/步骤/费用相关 | 服务、博客、规格 | 数据和条件有来源，图中重要信息也有HTML文本 |
| 包装/交付 | 最终收到什么 | 详情/服务 | 真实包装/交付素材，不能假装已履约 |

一张图没有独立任务则不加。首屏/章节/卡片视觉有主次；穿插大场景、局部特写、留白与信息密度，不把所有模块做同样的三卡网格。留白必须支持阅读，图片掉到下一行造成孤岛不是高级感。

## 2. 生产与绑定

图像简报写：用户问题、叙事、主体/动作/环境、构图/留白、色彩/光线、比例、桌面/手机安全区域、来源/授权、是否AI或概念、禁用元素、文件名与目标模块。优先原有可用素材；先做1张代表图实屏验证，再扩展系列。

保护真实产品主体；新增背景或修图不更改未知结构。生成品牌场景不能承担实际库存、认证或客户身份事实。需要证明的内容留待实拍。图片alt描述相关内容而非塞关键词；纯装饰图空alt；复杂图示另有文字说明。

导出按实际显示宽度/DPR，不把巨大原图交给手机。相同素材可用CDN响应式派生，不重复上传每个尺寸；width/height或aspect-ratio预留空间。首屏LCP图通常eager、适当优先级；下方图lazy；避免所有图高优先级。WebP/AVIF/JPEG按细节和透明需要选择，检查压缩后金属/宝石/文字没有失真。

证据：源素材→最终文件hash→平台asset ID→渲染URL→自然尺寸/解码→桌面/手机截图。文件库有图不等于模块已绑定；主题预览可能仍共享线上素材/商品。

## 3. 状态化交互，而非装饰动画

先为功能写状态：默认、悬停、键盘焦点、展开/选中、加载、空、失败、成功、禁用、减少动态/无JS。状态有文字/结构反馈，不能只用颜色或动效。

| 组件 | 推荐行为 | 必测 |
|---|---|---|
| 手机导航 | 原生流展开或可访问对话框，选一种清楚模型 | 焦点顺序、Escape、返回焦点；叠层模型防背景操作，流式模型不盖正文 |
| 页脚 | 桌面分组、手机按需折叠，短一级导航 | summary可键盘操作，隐私/联系路径不失联，线条与文字间距 |
| Tabs/场景 | 主动切换，无自动强播；tab/tabpanel对应 | 箭头/Home/End、aria-selected、tabIndex、只显示当前或清楚静态回退 |
| 图库 | 上一/下一、缩略图/轻量放大可选 | 手机点击与键盘均能使用，不能只靠hover、滑动或拖动 |
| 筛选/配置 | 保留选择、可清除、数量/摘要反馈 | 无结果、未知参数、返回恢复、旧配置失效；URL不承载隐私信息 |
| 表单 | 最小必要字段、明确必填、错误旁提示 | 错误聚焦/输入保留/防重复提交，真实成功确认与送达另测 |
| 阅读导航 | 锚点/面包屑/相关阅读 | 标题不被固定栏遮挡，返回路径明确，链接目标真实存在 |

动效的任务仅限方向提示、层级变化、确认或阅读进入。起步参考：按钮/反馈约120–220ms、面板200–400ms、一次性入场400–700ms；这些是设计范围，不是竞品实测或统一标准。小幅opacity/transform优先，避免布局抖动、滚动劫持、大面积视差与无意义常驻动画。若简单CSS/WAAPI足够，不加载大型库。

支持prefers-reduced-motion；当动画较多时提供可见的手动减少动态开关，并保持状态。减少动态应停止正在运行的动画、抑制新动画且内容立即可读。无JS保持核心内容和链接，不以初始opacity:0隐藏全页。自动移动/视频需可暂停等适用控制；不要把下载和电量成本藏在“高级感”里。

## 4. 实屏审查方法

按代表旅程逐步操作，记录视口/DPR/设备模拟/网络条件和动作，再截图并真正打开查看。先等待字体、懒加载可见图及过渡完成；长截图回到顶部，防固定控件合成假象。动态行为另用实际状态/动画记录验证，不靠静态截图判断流畅。

至少覆盖窄手机、常用手机、桌面；按内容断点追加平板/横屏或200%缩放。检查：导航字体、图片主体/比例、标题断行、图文节奏、触控间隔、footer、固定控件、空白孤岛、横向溢出、焦点。滚动经过并解码全部实际可见图；第一屏未见下方内容不是裁切，完整长图出现空白也可能是懒加载未到。

对发现的缺陷写复现步骤、预期/实际、选择器/模板、严重程度、最小修复和重测。两次同类补丁失败后查根因（重复全局选择器、模板覆盖、缓存、旧数据），不要继续堆!important。
