# 诊断与整改任务

复制本模板，每个主要假设一份；未知填“未取得／待验证”，不要填推测数值。

| 项目 | 填写内容 |
|---|---|
| 任务 ID／P 编号／状态 |  |
| 优先级及实际影响 | BLOCKER／SHOULD FIX／OPTIONAL；说明影响范围 |
| 目标和约束 | 购买／合格询盘；市场、成本、库存、履约条件 |
| 广告 ID／素材版本／主张 |  |
| 实际平台／版位／用户关系 |  |
| 最终 URL／页面版本／实际编辑来源 | 产品字段／单页／共享模板／应用／其他；影响范围 |
| 商品／变体映射 | 目录 ID、GA4 item_id、站内 product／variant ID；未知映射留空 |
| 时间与数据口径 | 观察与对照期、时区、币种、归因窗口、转化成熟等待期 |
| 观察事实 | 计数、分子分母、比率、样本量及证据位置 |
| 已取得资料 | D 编号、原文件／截图／报表、取数时间和覆盖范围 |
| 缺失资料及具体入口 | D 编号、所需字段、位置、负责人、缺失影响哪个判断 |
| 主要假设与证据状态 | 流量／衔接／内容／体验／交易条件／测量；事实或待验证 |
| 替代解释与反证 | 至少一个能改变决策的可能原因 |
| 验证方法 | 复现步骤／抽样／实验分流与对照；并发变更记录 |
| 商品内容整改 | 精确字段、修改前→后、商品事实依据；无依据填不适用 |
| 页面或流程整改 | 精确模块／控件／环节、修改前→后、范围；无依据填不适用 |
| 实施权限与负责人 | 是否已有具体操作授权；负责人与日期 |
| 主指标与验收依据 | 数据源、分子分母、基准、目标依据、样本和时长依据 |
| 商业保护指标 | 购买／合格线索、净收入／贡献、退款、其他受影响人群 |
| 停止／回滚条件 | 可接受损失、错误或保护指标触发条件；恢复版本 |
| 验收证据与结论 | 支持／不支持／样本不足／受混杂影响；技术成功与商业效果分写 |
| 剩余未知和下一步 | 只保留会改变决策的缺项 |
