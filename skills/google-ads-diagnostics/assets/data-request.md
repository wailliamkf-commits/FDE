# 按问题发出的最小取数任务单

只取支持当前决策的数据；具体入口按技能入口链接的 data-sources.md 查找，菜单变化时用稳定报告名称搜索。

要判断的问题／决定：
已获得、无需重复索取的数据：

|优先级|数据与用途|系统／菜单或报告名称|账户／日期／过滤条件|字段／粒度|导出格式与负责人|缺失时影响什么判断|
|---|---|---|---|---|---|---|

交付要求：

- 附时区、币种、日期口径、转化动作、导出时间、过滤条件和范围。
- 费用基表与转化动作表可分别导出，保留真实 ID；不要人为复制动作级费用。
- 图片保留标题、日期、筛选条件、表头和相关行；无法提供的范围标未知。
- 订单／线索保留必要脱敏标识与阶段，删除不必要的姓名、邮箱、地址、支付凭据和个人信息。
- 明确只读：不修改广告设置、不保存目标、不发送弃单恢复邮件、不创建新的集成。
- 若权限或保留期导致不可取，说明缺失范围，提供已有合法等价数据，不声称完整覆盖。
