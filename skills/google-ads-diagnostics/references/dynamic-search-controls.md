# 动态搜索：页面池、诊断与适用边界

## 先确认当前能力

2026-09-28核验：Google已把DSA自动升级至AI Max的启动时间延至2027年2月；这不证明某账户当前仍用旧DSA或已迁移。先核对实际系列/广告组类型、迁移通知、搜索匹配、文字定制和最终URL扩展设置，再选择对应配置。维护的是“可控页面池→真实需求→商业验证”方法，不把某广告产品名称固化为永久架构。[官方升级公告](https://blog.google/products/ads-commerce/dsa-upgrade-to-ai-max-2026/)

DSA依据网站内容与搜索相关性匹配，不是预先逐个挑中“精准客户”的保证，也不是给全站价值打分的工具。选定页面池能约束可投内容，无法保证每页都有流量。当前其他搜索自动化能力需重新核验URL规则，不能直接照抄DSA设置。例如AI Max开启最终URL扩展时，URL inclusions不保证只投这些URL；须核对扩展开关、可用限制和实际到达页。[AI Max设置](https://support.google.com/google-ads/answer/15909989?hl=en)

## Feed与页面资格分清

| 层次 | 实际要核查 |
|---|---|
| 已收集 | URL/SKU/变体的分母、去重、日期和采集覆盖；脚本成功不等于目录完整 |
| 已提交 | 页面Feed与商品数据源分别是什么、提交条数、规则和错误 |
| 可投资格 | 动态目标/页面状态，或商品目标国家与具体投放目的地状态；暂停、未选中和拒登分开 |
| 实际触达 | 有展示/点击的独立URL或商品及覆盖窗口；分母一致后才计算覆盖 |
| 商业验证 | 成熟购买/合格机会、贡献、退货和供给；“符合条件”不等于卖得动 |

页面Feed用于URL与页面标签，GMC商品数据用于商品属性及相应商品广告；不从两种行数推断商品遗漏。所谓“覆盖全产品”需要目录映射和目标设置证据，上传了所有URL不足以证明实际覆盖。

DSA页面池优先去重并使用有效最终URL，排除失效、不可售、登录/购物车/政策等不适合本轮需求的页。检查AdsBot可访问、页面可读、目标规则、负向目标、品牌/查询排除及国家语言。第三方抓取失败不证明AdsBot失败，站点SEO索引状态也不能替代广告抓取状态；用目标诊断与获授权的服务日志核实，不默认解除全站安全限制。

对旧DSA明确选择“仅页面Feed”还是“索引＋Feed”，不能只上传Feed就声称范围已限制。单URL可用多个页面标签，不为每个维度复制URL或建一个系列；多维探索防止样本、预算与页面归属重叠。上传到可投有延迟，Google提供的常见抓取时间是参考而非订单承诺。[页面Feed规则](https://support.google.com/google-ads/answer/7166527?hl=en)

GMC不可用时，无商品Feed的合规搜索路径在技术依赖上可以不同，但不绕开Google Ads账户、行业、地区、广告和目的地要求。核查限制原因与申诉/修复路径；切换类型不是解除停用，也不采用中性文案、跳转或隐藏真实内容规避审核。不要把某一敏感类目在所有国家一概判定为可投或不可投；DSA本身对部分敏感行业也有适用限制，因此不能当作GMC不可用时的通用备用路线。

## 花不完预算时，按证据排查

先确认“预算”指日均设置、共享预算还是实际可用资金，并记录变更时间。增加预算不会保证增加合格流量，更不能证明买到了额外抓取算力。

| 候选约束 | 最小证据 | 对应动作与等待边界 |
|---|---|---|
| 账户/广告/页面资格 | 账单、暂停、政策、动态目标状态、抓取错误 | 修复具体阻塞；状态不恢复时不能只等学习 |
| 页面覆盖/需求 | 有效目标、Feed来源模式、语言地区、排除、查询与实际落地 | 修错或受控扩展；少数页曝光不能推断全市场天花板 |
| 竞价与目标 | 当前策略、tROAS/tCPA、近期调整、可用竞价指标 | 结合贡献底线测试，不为花完预算盲降目标 |
| 预算与流量机会 | 预算限制状态、共享预算竞争、实际费用与可用机会 | 仅在预算构成约束且风险可承担时测试加码 |
| 测量/学习/延迟 | 目标值质量、策略状态、转化延迟、最近变更 | 修追踪并隔离未成熟窗口；不能用学习解释所有失败 |
| 承接与供给 | 相关查询后的路径、价格/交期、库存、支付或询盘 | 验证产品或页面约束，不能从低费用跳到网站无价值 |

观察应分三只钟：抓取/审核可投进度、出价与投放适应、购买/退款/商机成熟。等待必须指定所等信号、下次检查、花费上限及超时动作；“48小时”“一两周”不升级为通用完成期限。平台无阻塞也不等于数据量足以判断商业价值。[DSA低流量排查](https://support.google.com/google-ads/answer/2549052?hl=en)

预算、出价目标与流量会共同影响实际展示；不要用“抓取与预算不是同一过程”推导成“预算与投放量无关”。2026-08-17起的目标出价更新尤其影响预算受限的系列：若此前实际效率优于设定tCPA/tROAS，之后可能更接近所设目标。历史前后比较保留配置、适用性和变更记录，不能把所有波动都归给新结构或这一政策。[目标出价变更](https://support.google.com/google-ads/answer/17061251?hl=en)[tROAS说明](https://support.google.com/google-ads/answer/6268637?hl=en)

## 拆分后的边界仍需回读

系列名字不形成流量隔离。核验可用的品牌控制、查询否定、商品范围、最终URL扩展及动态目标；按当前平台规则确认适用网络和限制，不承诺所有查询均可见。重叠不天然有害，也不是独立试验；根据角色和总经营结果判断是否保留。

PMax可能进入多个渠道。符合资格且与查询相同的精准关键词在相应搜索规则中优先，但预算、审核和定位会影响资格；不能据此宣称所有Search都优于PMax。相同商品和定位重叠的Standard Shopping与PMax目前按Ad Rank决定，不能沿用PMax总优先的旧说法。Search规则不等同Shopping广告格式的规则；均需回读实际账户。[搜索优先级](https://support.google.com/google-ads/answer/2756257?hl=en)、[Shopping与PMax](https://support.google.com/google-ads/answer/13975266?hl=en)
