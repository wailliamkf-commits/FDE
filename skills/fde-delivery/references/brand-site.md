# 从渲染图到可信品牌站

可选的通用参考，不包含任何客户的实时产品事实。

需要从市场研究到页面、视觉、自然流量与发布的完整流程时，优先调用可用的 `fde-brand-site`；本短表仅处理已有真实产品资产的局部交付，不代表所有行业都应采用零售或定制模式。未安装该技能时不自动安装。

1. 原始资产清单：型号、视角、真实结构、颜色、配件、尺寸/比例、来源与使用权；原件只读。
2. 用户决策：这是什么、适合谁、如何选择、如何使用、需要什么证明；先做结构和图片简报。
3. 图片分类：产品身份图、明确的场景示意、真实证据。不能生成假工厂、假测试、假认证或假案例。
4. 优先保护真实产品主体，以抠图、合成、背景扩展为先；未知背面、接口和结构不猜造为实物。
5. 桌面与移动端分别构图；标题、参数与利益表达尽量保留为可编辑页面层。
6. 卖点链条：已验证事实 → 用户选择 → 有边界的利益 → 来源。数据缺失保持空缺或请求确认。
7. 验收：产品一致、无未证实功能、正确素材绑定、移动端、可访问性、性能与实际路径。
8. Shopify 的主题预览不隔离共享商品数据；修改 Products/Variants/Media 必须单独核实授权。

首任务：一款产品的事实与资产对账，或一个确实存在的页面问题；不要先生成几十张图掩盖数据和模板错误。
