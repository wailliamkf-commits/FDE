## 从历史讨论保留什么

本轮输入是用户提供的13张聊天截图。第一轮重点提炼接手人的结构思路，未读取广告账户；背景、操作进度和效果声明均不能替代当前后台。截图存在重复段落，部分只显示相对日期；嵌套转发诊断与本人表述分列。原图、发言人及客户细节留在本地项目工作区，仓库仅保存通用方法。

可复用主线：保住有效路径 → 用合格页面探索现有需求 → 连接查询、页面、商品与成熟结果 → 商品分层 → 按需求角色逐步重构 → 验证新增贡献 → 将承诺传递到交付与使用体验。

| 聊天中的思路或判断 | 本轮处理 |
|---|---|
| 大目录且选品证据不足，先整理页面再探索 | 采用条件方法；动态搜索是候选工具，覆盖与数据偏差必须可见 |
| 先过渡获取数据，再优化商品标签和购物广告 | 增加保留旧有效路径、风险限额、恢复条件；不固定为先停购物广告 |
| 按多个维度组织Feed | 区分页面Feed和商品Feed，URL去重、真实商品映射，不硬编码维度名或系列数 |
| 转发并认可品牌承接/探索/商品验证的角色设计 | 保存候选分工；认可诊断不等于已经执行全部配置 |
| 早期估计几天或几周，后来强调不能只看天数 | 使用抓取、投放适应、商业成熟三类观察条件；等待有截止检查和停止动作 |
| 跑不满说明网站价值只有这么大 | 不采纳因果判断，改为资格、覆盖、需求、竞价、预算、测量与承接的诊断树 |
| 算力由网站层级决定，历史消耗让现在更快 | 未证实解释；历史转化信号与既往花费分开，不形成权重回报理论 |
| 无GMC就换DSA | 拆成技术依赖与政策资格；敏感行业也可能不适用DSA，不作为规避路线 |
| 主体商品内容优先 | 采用商品事实与上市标准；不据此否定服务不同意图的辅助页面 |
| 最后多数由品牌词承接 | 留作待验证路径假设，不作为全部增量归属或结构成功指标 |
| 开箱、交付和使用体验积累品牌记忆 | 转成低成本触点试验，记录队列、投入和实际结果，不保证私域优于付费 |

## 第二轮：只读历史复核（0.1.12）

用户授权只读查看后，在其现有原生浏览器窗口读取历史摘要并展开关键记录；没有调整广告内容、预算、出价、目标、启停、Feed、筛选或列配置。原始记录、账户信息、完整覆盖与未知项留在用户本地项目工作区，不写入通用仓库。

新增 [操作历史复核](../../skills/google-ads-diagnostics/references/change-history-review.md) 与 [空白工作表](../../skills/google-ads-diagnostics/assets/history-review.md)：

- 区分报告期表现、当前配置和历史事件；记录原视图过滤、分页与批量子项覆盖，不将可见视图等同全账户。
- 按稳定对象及时间重建有效区间，分开组合策略、共享预算、名义目标、探索容差和新客追加价值。
- 目标类别与具体转化动作、生成内容准则与流量排除、系列名称与子组实际目标分别核对。
- 保留操作者身份、未知列表内容和未成熟窗口；只读复核不会调用撤销或执行真实试验。

[5项合成行为测试输入](../../skills/google-ads-diagnostics/assets/history-eval-cases.json) 覆盖：历史期与当前状态混用、同批多字段及身份猜测、边界日期和筛选缺口、浏览器会话不匹配、组合预算/探索/新客价值依赖。全部为虚构数据，可离线复演；测试目标是判断和补数的正确性，不是关键词匹配。

验证结果：133项标准库回归通过；Google技能结构校验通过；138文件精确清单、JSON/相对链接检查通过。独立模型完成5项离线情境演练；根据反馈明确容差算例仅为有条件算术示意，并明确既有授权下直接盘点正确只读窗口，受影响案例复核后无阻塞。真实现场读取与离线演练分开记录，均不证明业务成效。
