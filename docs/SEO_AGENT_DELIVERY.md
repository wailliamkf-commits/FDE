## 成体系不等于所有项目都做一遍

需求/采购阶段 → 查询与意图簇 → 页面职责/资料 → 内容与技术工作包 → 小范围验收 → 真实运行观察 → 成熟商业复盘。

每条链都包含“输入、责任人、产物、验收、回退”。缺数据可先交低依赖人工方案；缺权限只阻止相关变更，不阻止只读诊断。出现多个URL先判断用途，不自动删页；已有CMS就沿用，不为了工具箱迁移建站平台。

量化分三层：交付覆盖与错误、运行中的曝光/体验/接收、业务中的有效线索/合格商机/成熟贡献。目标由当前基线、购买周期、样本和资源决定，不保证固定时间获得排名或收入。
