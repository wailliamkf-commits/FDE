## 从会议到技能的处理

| 会议主题 | 处理 | 技能中的可执行补充 |
|---|---|---|
| 市场、用户、竞品先行 | 采用并收紧证据边界 | 四类证据、实际购买经历、未购买/退货反例、供给验证 |
| 持续存在的竞品模块值得学习 | 改为候选假设 | 观察不等于有效；用可比人群与自身结果试验 |
| 产品、场景、服务共同组织网站 | 采用 | 先复用已有页面；新URL需独立意图与维护条件 |
| 广告与SEO互相支持 | 采用协作，不采用排名因果 | 查询和问题双向交接，分开商业验证；广告不会购买自然排名 |
| 历史广告投入返还、短期必然改善、堆页产生质变 | 不纳入规则 | 时间、数量与渠道比例由真实数据和试验决定 |
| FAQ、AI与隐藏内容 | 改写 | 待答问题内部保存；公开内容需事实支持，正常折叠不等于操纵隐藏 |
| 活动与移动端 | 增补验收 | 广告到商品/结账承诺一致；优惠真实、到期撤除、真实设备闭环 |
| 定制与项目询盘 | 分支化 | 先验证人工报价闭环，再按容量与权限需要评估系统 |
| 登录隐藏定制商品以避开权利争议 | 不纳入规避做法 | 隐藏不产生权利；未明项先HOLD、核实来源 |
| 跨部门卡点 | 采用并量化 | 接收、等待、制作、返工、上线时间与机会窗口 |
| 域名、双站、平台扩张 | 改为条件决策 | 迁移影响审计；平台成本、替代效应与自有资产分开 |

以上是方法提炼，不是逐字引述或对发言人的归责。官方机制链接见 [协作参考](../skills/fde-brand-growth/references/search-site-collaboration.md#机制核验来源)。
