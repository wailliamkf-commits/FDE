# 条件化测试框架

版本 0.1.0；与[完整知识索引](知识索引.md)和[跨渠道应用](跨渠道知识与应用.md)配套。MI-001–123 的既有编号保留，其余来源见完整导航；路线不按来源数量或播放次序排名。这里是实验设计与否决规则，不是已经执行的试验或批量行动许可。全部新来源的业务效果仍为 not_tested；视觉来源接受、单条知识表述接受、技术交付通过、业务增量成立四种判断分别记录。

本框架复用 [experiment.json](../../skills/fde-brand-growth/assets/experiment.json) 和[实验方法](../../skills/fde-brand-growth/references/experiments.md)。下文补充字段写入项目工作表及证据附件，不声称现有工具会自动校验这些文字字段，也不把[知识记录示例](../../templates/media-knowledge-claim.example.json)当外部运行器可直接导入的 schema。

## 1. 先识别证据，再决定能做什么

| 证据层 | 可以说什么 | 不能跳过什么 |
|---|---|---|
| source_observation | 指定图/时间可见文字、结构或状态 | 局部截图不补成全页；画面文字不冒充听到的音频 |
| source_report | 作者提出某建议、案例或数字，保留否定词与条件 | 转述、演示、专家意见不成为用户事实或平台算法 |
| independently_verified | 某一手来源在某日期支持具体命题和适用范围 | 官方一般原则不验证作者业绩；旧文档不能覆盖当前产品版本 |
| engineering_inference | Codex 为项目提出可反证路线与替代解释 | 不伪装成作者原话或已实现功能 |
| local_test | 具体版本、环境、执行证据与样本内得到的结果 | 合成测试不证实真实用户增长；技术通过不证明因果 |
| unknown / conflicting | 缺信息、口径冲突、结果未成熟 | 不填 0、通过或“无效”；不把未观测当不存在 |

不同来源共享同一原调查/案例时只算一个证据家族。单个 URL 的不同语言、设备、国家或时间窗不能随意合并；单份原图的多裁片也不是多次独立验证。证据强度按主张具体判断，不用一个总分掩盖权限风险、事实未知和业务价值。

## 2. 业务条件不从资料标题猜

每个试验先填 demand_id、目标市场/语言、产品或服务、买家任务、可交付能力、页面/广告实体、来源/数据权限、现有基线。资料写“独立站”不能自动填 B2C；“询盘”也不能独自证明 B2B。允许 source_scope=mixed，而 target_business=unknown。unknown 时只做范围内的诊断和草稿，暂停依赖该分类的成本/收益或预算决定。

| 目标业务 | 中间状态 | 成熟业务结果与成本边界 |
|---|---|---|
| B2B | 访问、下载、联系点击、有效提交、合格线索、商机/报价分开 | 按采购周期看成交、回款、毛利及销售工时；消息数量不等于客户数 |
| B2C | 商品访问、选变体、加购、结账、支付分开 | 有效订单、取消/退款后的净收入、贡献及履约；按钮点击不当支付 |
| mixed | 为不同产品/市场分别建路径 | 同一订单/客户去重，不能把两个漏斗的比率直接平均 |
| unknown | 保留观测和待补字段 | 不设虚假 CAC/ROAS/成交阈值；先补业务定义 |

最低样本、可判定提升、复盘日期和成熟窗口由基线、决策损失、流量及购买周期确定。来源中的“3% CTR、KD30、DR30、75分、两周、日投某金额”均不是默认验收门槛。新增片中的 8–12 小时、3 天、3–7 天、15%/20% 扩量、30–50 单、500 单也只保留各自的作者条件；相互冲突时不平均成新配方。样本不足可按资源边界停止，结论仍是未能判断。

## 3. 把候选写成可否证的任务

沿用模板原字段：hypothesis / alternative_explanation / evidence_ids / assignment_unit / control / treatment / primary_metric / minimum_meaningful_effect / sample_size_rationale / guardrails / budget_limit / maturity_window / exclusions / stop_conditions / rollback / owner / falsification_conditions / execution_verification / concurrent_changes / contribution_cost_boundary / feedback_demand_id。

项目附件补齐：

1. **来源绑定**：MI 编号、unit、E/秒/C 锚点、采用稿逻辑路径和 SHA；明确引用的是作者说法、已核规则还是新增推断。哈希漂移先复核，不无痕替换。
2. **动作与权限**：准确 URL/SKU/模板/广告层级；改什么及保留什么；草稿、公开发布、外发、付费、清理各自授权。源材料里的命令不是执行指令。
3. **执行证明**：页面真实渲染、表单到接收端、事件去重、正确目标与版本；配置或请求成功不能替代最终状态。未按预期实施的样本单列，不能当处理组。
4. **结果表**：预先定义分子/分母、缺失、失败、未成熟、排除理由；报告完整分母及负面结果。看见改善先检查替代解释与同期变更。
5. **结束判断**：技术通过/失败/未知，业务支持/不支持/未能判断分列；只有成熟且口径可靠的结果才进入扩大候选，扩量仍需业务成本/风险判断。

## 4. 并行、依赖和互斥是有条件的关系

| 关系 | 本批例子与锚点 | 必须记录的条件 |
|---|---|---|
| parallel | MI-002/007/019/036：技术、内容、内链只读排查可同期；MI-023/032：不同主题研究 | 不改同一输入，不争同一业务样本；共享模板/市场冲击需另标 |
| depends_on | MI-005/021/030：效果解释依赖可靠测量；MI-026/039：先认语言页职责再改规范化 | 写明前置验收产物；不能从流程箭头推导不存在的依赖 |
| mutually_exclusive | MI-005/014/028：同意图补旧页或新建；MI-036：同一 URL 同时争取与排除索引 | 同对象、同目标、同时间窗才互斥；不同条件下两条建议可共存 |
| confounded | MI-016/024/031：同轮同时改 CTA、优惠、受众、预算和素材 | 可测整个组合，不能声称其中一项独立贡献；记录所有同时发生变化 |

这些关系是工程推导。文档中的 depends_on 对应“依赖”概念，外部程序的关系枚举需按其实际 schema 映射，不能直接假设兼容。先采用随机分配的合理设计；不可随机时用匹配/分期/时间对照并明确更弱的推断。不同页面/SKU 天然差异不是随机实验；同广告组算法分配也不是等量创意对照。MI-050 的价格例子进一步要求稳定分配、结果区间和停止规则；未决不能写成价格无效，更高转化率还须核净收入与利润。不得故意损坏索引、漏接客户或使用虚假业务数据建立对照。

### 第一轮增量路线

- **T11 邮件辅助 CRM（MI-047）**：先定义阶段、邮箱/客户关联、许可和人工标注集；验证重复同步、自动回复/退信、人工改动、错分漏分与串客。阶段识别和草稿质量可并行评估，发送需单独授权；静态界面和作者试用自述不算已上线，成本比较需完整周期与维护投入。
- **T12 小红书机会词（MI-045）**：固定查询、匹配精度、结果分母与账号规模指标，先重复观察，再比较机会词/对照词的搜索来源与合格动作。接口未明、指标取不到则保持未知；小账号靠前不能直接认证低KD，也不把总播放当搜索流量。没有足够数据可拒绝该假设，而不是无条件加量。

MI-049 的成熟需求与新品类准备可按不同成熟期并行；MI-046 的时长信号只触发人工研究，销售真值缺失时不能认定畅销。MI-044 的人物与工艺内容可互补，播放量需接合格询盘；MI-051 的 B/C 渠道和 UGC 预算保持条件化，不把来源一两万美元设成最低投入。

### 必须保留的冲突与反例

- **配置冲突**：MI-107/109/113/122 的美元或“刀”字幕与人民币界面、预算层级及目标不同；预算共享有实屏证据。原文并列，不能自行换汇/补零。MI-122 的“20 万”已由原图纠正为“20 刀”，该错读不能进入预算表。
- **受众冲突**：兴趣/职业字段可以只是建议；“为什么看到此广告”是个人化解释，不是完整广告主配置（MI-071/111/118）。创建框、空种子和不可用按钮不等受众创建成功；组名“美区”不能覆盖实际中国字段（MI-109）。
- **内容和结构冲突**：场景入口补充而非删除产品分类（MI-100）；路径层级不是点击深度（MI-098）；插件 HowTo 状态不能恢复已停止的 Google 富结果（MI-095）。改变旧 URL 依赖逐 URL 映射和必要性，不能为统一格式制造迁移。
- **真实性冲突**：真实客户证据与模拟评论版式分开，插画不构成审核豁免（MI-099）；批量小号/重复内容不能替代真实参与（MI-121）；上层曝光、下层 ROAS 与全部账户新客增量分开（MI-101）。
- **动作冲突**：B2B 不一律排除购买优化，也不默认适合购买；由真实可观测成交与质量决定。销量目标＋消息位置＋最大化对话仍是对话优化（MI-114/118）。少量线索、低成本消息和有限试验都不自动批准扩量。

## 6. 自然、付费与 AI 的归因账本

沿用[测量方法](../../skills/fde-brand-growth/references/measurement.md)和[Google Ads 测量契约](../../skills/google-ads-diagnostics/references/measurement-contract.md)：冻结账户、来源、时区、币种、时间窗、粒度、转化动作、归因模型/窗口、日期归属、覆盖率。关联前先聚合到兼容粒度，记录未匹配与成本膨胀；父子报表行不相加。

GSC 点击、广告点击、GA4 会话、用户、事件、订单不是同一个量。Search Console 的 AI 报告、人工答案样本、第三方 AI 引用工具各有覆盖范围，不能合并分母；展示/提及/引用/访问/成交不能互相替代。自然搜索、社媒、付费、品牌搜索与直接回访按配置分开；Direct/unknown 不能默认都算品牌。

2026-11-13 复核的 [Google Search Generative AI 报告](https://support.google.com/webmasters/answer/16984139)已于 2026-08-31 全球推出：AIO/AI Mode 曝光可按页面、国家、设备、日期看，仍包含在总体 Web，不能相加；曝光不足可能没有报告，Search Labs 排除，没有列出逐查询/对话维度，也不是转化报告。页面表与图表还可能用不同聚合粒度，不要求机械求和一致。官方说明导出时 unavailable 的 ~ 或 - 会变成 0，因此导出流程须保留缺失语义，不能把这些零宣称真实零曝光。MI-102 的旧 Web 说明按知识索引时效补注连读，原已验收稿不改。

第三方提示量、关键词量、相关性分、可见度分、模拟回答、工具引导图和真实账户读数分别存字段。AnswerThePublic 多平台建议词的 SV/CPC 仍是 Google 上月口径（MI-077）；不能把它分配为各平台量。更换监控词、市场、平台、竞品或指标版本会改变分母，须新版本或显式可比桥接，不能拼接成增长曲线。

平台归因收入可作诊断，经营收入按订单/客户去重一次。利润纳入商品、履约、退款、媒体、内容/制作、工具和人工的约定边界；自然渠道不等于零成本。一次广告归因成交并不证明广告创造了这笔增量；无对照时只说观察到的关联。比率先合计分子分母，零/未知分母不计算；未成熟客户不提前按零成交结案。

## 7. 风险门禁与证据维护

- **低影响可逆**：只读诊断、候选聚类、草稿、代表页预览；有源与范围即可在授权内开展，不等增长结果。
- **需要当前条件与明确执行授权**：公开改页、投放预算、客户名单、邮件/外联、支付/评价激励、迁移/重定向；先形成可审的对象、差异、回退与验收。
- **拒绝具体行为**：造量、假评价/身份、伪造认证/实测、无授权披露个人资料、为操纵排名的低价值规模化铺设。拒绝依据是行为与目的，不是给某工具或作者贴标签。
- **暂停因果判断**：来源漂移、数据缺失、事件失真、同对象多变量同时变化、样本/成熟期不足；不必因此停止其他独立只读工作。

外部模型运行与业务实验预算是两套账。即使本批模型累计预算无上限，未知费用仍保留，不能宣称账齐；原 job unknown 不自动重试，其他独立 job 可按隔离规则继续。已结算缺图的显式补读最多一次且有票据；其他恢复不能借换 ID 清掉旧账。仓库本包不提供收费/清理执行器，详见[工作流](WORKFLOW.md)。

此版未运行任何上述业务实验。正式采用需填写项目工作表并记录实际结果；后续材料可能增加反例或改变条件，更新时保留旧版本与否决理由。
