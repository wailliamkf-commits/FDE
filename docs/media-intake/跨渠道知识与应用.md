# 跨渠道知识与应用条件

本页把媒体中的方法与 FDE 原有能力连接起来。它是可选择的路线图，**未在用户站点上验证商业效果**；完整来源定位见[知识索引](知识索引.md)，当前规则与旧说法的纠偏见[时效核查](时效核查与纠错.md)。原作者数字、示例账户、工厂规格和成功叙述不得自动变成新项目事实。

## 1. 先选业务问题，再选渠道

保留 SEO、Google/Meta 广告、AI 搜索、Reddit、YouTube、社媒、邮件和独立站运营，不预设其中一种必胜。先用现有 [需求记录](../../skills/fde-brand-growth/assets/demand-record.md) 固定产品、买家、场景、市场、可交付能力、目标行为和未知；再选择能验证该需求的最小渠道组合。

| 业务模式 | 网站和内容主要解决什么 | 成熟结果与反例 |
|---|---|---|
| B2B 标准件/工业产品 | 规格、适配、工况、供货、质量文件、MOQ、交期、询价和技术沟通 | 访问→有效联系→产品/地区/采购条件匹配→报价/商机→成交/回款。联系多而销售处理成本更高，可能没有改善 |
| B2B 定制/服务 | 能力边界、真实过程、可验证案例、需求采集、约束与方案确认 | 提交需求不等报价完成；报价不等签约。周期未成熟时保留待决，不按零成交结案 |
| B2C 零售 | 真实商品、尺寸/兼容、价格、配送、退换、选择和支付 | 点击/加购不等订单；订单扣除取消退款再看贡献与履约。提高转化却损害毛利可能失败 |
| 订阅/软件 | 任务适配、激活、付费、持续使用、支持与退出 | MRR、收入 LTV、贡献 LTV、现金分开；增长不证明留存或盈利 |
| 混合/未知 | 不同人群和路径分开记录，补足事实 | 独立站、博客、询盘这些词不足以判 B2B/B2C；不能平均两种漏斗的转化率 |

并行研究允许保留替代路线。修改同一页面的内容、设计、价格、受众和预算可以作为一个组合试验，但不能事后归因给其中一个动作。先后顺序由真实依赖决定，不由视频播放顺序决定。

## 2. 关键词与页面职责

把工具建议词、真实客户问题、竞品页面和搜索结果类型合并成研究清单，保留原始词行、国家/语言、日期、数据源、量与未知。KD N/A 不是 0，第三方搜索量不是销量，多个工具的分数不可直接拼接。

先检查已有页面能否承担意图，再决定更新或新建。主页、集合/分类、产品、方案、比较、教程、资料与工具页各有职责；一词一页和把所有长尾塞主页都是需要反证的极端。一个页面覆盖相关意图可以合理，多页面服务不同买家任务也可以合理；关键是独特价值、清楚入口与维护责任。

来源 `u-af5eebd68e336d62ddeb` 用 SERP 文章占比与进前十比例作经验比较。可保留“研究结果类型再选择页面形态”，不可把观察到的比例当新站成功率；屏幕仅展示的八条结果也不能无痕补成十条。`u-5da6a3638005847ff2ba` 的冷门词和技术知识区提示可探索产品参数、工艺、材料、编程、计量及专用计算器；但子域迁到主域、PR 和外链同期发生，不能识别哪一项造成增长。

**可测试交付：** 意图—现有 URL—待补事实—页面职责矩阵。拒绝无业务供给、只是换词复写或没有维护人却批量铺页的方案。

## 3. 内容生产与 Agent 协作

可用的分工是研究事实、准备引用与数表、起草、核查、读者任务评估、页面实现、发布回读和复盘。按任务选择确定性程序或模型；文件拼装、哈希与覆盖计数不必再付费让模型重写。模型可以产疑点，不能自证事实。

数表至少记录原句、来源、日期、单位、工况、分母、支持范围与反例。工业文章须保留型号、材料、公差和标准适用条件；没有泵曲线却回答统一的功率—扬程数字，属于虚构精确性。自有照片和“工厂经验”仍需来源和真实权限，不能为制造独特性编案例。

`u-af5eebd68e336d62ddeb` 的“答题 AI 只读文章，判卷 AI 对照研究表”可发现缺口，但“答不上＝没写到”不成立：可能漏读、题目欠条件或评分表错。另一模型给高分、单元测试通过、HTTP 201、页面已发布、客户任务完成必须分层验收。

`u-d90c1997b09b8da54f5c` 的工具改名绕过约束及写入事故说明：提示词规则、接口行为和执行边界需分别测试，测试用例不能只检查预期工具名。恢复需确认真实改动对象、版本、回执、失败与回退，而不是重置账本或手写“通过”。这段是事故材料和工程推断，不说明 FDE 已具备生产网关。

可并行做事实对照、可读性和需求覆盖检查；未解决事实冲突的内容暂停发布。用错误率、人工纠错、总耗时、失败率和实际交付质量比较工作流，不能用生成篇数、角色数或人数缩减自述替代收益。

## 4. 技术 SEO、内链与多语言

按发现→抓取→索引→展示→点击→业务动作拆状态。site 查询不是完整索引计数；URL Inspection 的索引版本、实时测试和请求抓取也不是同一操作。`u-b4aab14529151d037bf1` 中“137 站仅能判断 94 站”必须留下 43 个未知；没有正文来链也不等于没有菜单/分类入口的孤岛。

先列应公开且应索引的页面，再查响应、robots/noindex、canonical、站点地图和可抓链接。无需索引的过滤页、测试页或重复页不为提高比例而开放。新文发现技术错误可立即修，不必等待作者的固定天数；长期未索引也不能一律判为内容差。

内链从真实阅读任务与页面关系出发。精确词匹配不保证相关，包链接仍是页面改动；检查已有链接、重复嵌套、目的页、预览和公开回读。老文→新文、分类→产品、文章→资料/商品可互补；不固定每篇三条或强制全部指购买页。

语言页需市场、内容、货币、规格、可供货、URL、canonical/hreflang 和维护版本协同；不同语言不是把主站复制几遍。改旧 URL 前做必要性判断、逐 URL 映射、重定向与恢复，不能为了统一外观制造迁移。

性能优化以真实页面功能和场景为前提。现场数据与实验室诊断分开，修复要回归菜单、变体、表单、支付与测量。不能为跑分删除真实买家任务或必需事件。

## 5. GEO、AI 引用与平台动向

AI 搜索是新增发现路径，不意味着 SEO 无效。保留站内可用内容、可核引用、第三方描述、真实品牌资料和多渠道接触，同时建立固定问题样本。不同平台、语言、联网/登录状态与模型版本分别记录，失败和无结果不能隐去。

“被提及”“描述正确”“引用了 URL”“有人访问”“产生合格行动”是不同结果。第三方模拟回答不能冒充真实用户需求或官方排名；把泛问题改成高度贴合产品的长尾后排名靠前，不能称同条件提升。论文中的特定指标也不等于全站访客增幅。

`u-ce9b151d68e1da8e1c04` 的 AI/自然会话比例、历史表单总数和刚启用的事件口径不同；看板来源分类之和还与总量有差。可迁移的是先核 API 参数、分类代码、时间窗、测试流量和去重，再用看板决策。不得把无法归因的 Direct 都分给 AI，或把 PR 后出现流量判成 PR 因果。

机器人训练、搜索发现和用户代理请求分开制定策略；实际读取服务的文档、站点设置和日志，不能照搬“一键挡 AI”或“全面放开”建议。平台变更登记日期、地区与账户资格；[时效核查](时效核查与纠错.md)中的新规则不追溯证明视频当时正确。

## 6. Google Ads 与 Meta Ads

沿用原有 [Google Ads 2.2](../../skills/google-ads-diagnostics/SKILL.md) 与 [Meta Ads 1.1](../../skills/meta-ads-diagnostics/SKILL.md)，先做测量、真实账户配置、商品/页面与历史操作的只读诊断。视频中的预算、归因窗口、学习期、扩量比例和“几天关广告”均须带场景，不覆盖现有方法。

Meta 的系列目标、转化位置、成效事件、Dataset/Pixel、渠道连接、预算层级/共享、受众控制与建议分别回读。名字叫“美区”却选中国、作者说美元却界面人民币、口头说只收手机却保留邮箱与可选手机，是应保留的配置反例。ABO/CBO 或宽泛/兴趣受众可以按条件测试，算法不等量分配不构成公平随机对照。

`u-a1bbb1ce079ad35b868b` 结尾仍草稿、缺素材与表单，不能作为发布成功样板；网站与原生表单的质量取舍需看有效联系、合格量、成本和销售工时。验证手机号不认证企业或采购权，额外一步也可能流失真实客户。保留作者对 Messenger 历史有效的例外，不能机械排除版位。

Google Search、Shopping、PMax、Demand Gen 的实体和信号不同；从查询/商品/页面任务找到具体问题，再考虑结构重组。缺量可能来自资格、预算、出价、供给、页面或测量，不直接等于无市场。变更历史、当前配置和历史表现分开，广告效果不从按钮或教程自动继承。

可测试的最小交付是一个明确需求—素材—目标页—事件链及完整基线。扩量前看成熟结果、边际成本、现金与履约，不能只凭 CTR、低 CPL、平台 ROAS 或一两单。

## 7. 从广告倒推素材、落地页与产品视觉

竞争者广告库、持续投放时间、点赞、评论和“为什么看到广告”可提供研究线索，不给完整定向、利润或真实销量。拆解应记录可见承诺、买家任务、视觉证据、CTA、目标页、商品/价格/交付限制；缺数据的格子留空，不用 AI 补成竞争者策略。

素材按任务准备多种候选：问题识别、使用过程、比较差异、真实制造/测试、社会证据和真实优惠。形式胜出不证明内容主张真实；插画不豁免健康广告审核，模拟评论排版不等于用户证言。原创改写也不能移植别人的认证、测试或个人体验。

落地页承接同一承诺，保留移动端可读、完整图片、规格、选择、价格、信任依据和下一步。页面简洁与信息完整可兼容；B2B 规格/定制路径和 B2C 变体/支付路径按任务分开。竞品有一块模块，不等于用户也必须有；先用 [页面与视觉契约](../../skills/fde-brand-site/assets/visual-state-contract.md) 定义对象和状态，再验证真实交互。

测试可以同时保留多个卖点方向，但要登记素材版本、对象、实际花费和送达；无量素材单列，不能称其已证明失败。自然高互动素材可进入付费候选，不保证付费成交。

## 8. Reddit、YouTube、社媒、UGC 与外部引用

把搜索需求、内容价值、真实参与与分发许可放在账号数量之前。社区先读版规和实际问题，提供能独立成立的回答；外联记录拒绝、无回应、链接属性和后续结果。真实关系、授权体验、产品限制和赞助披露不能省略。

YouTube 和社媒可测试人物、工艺、产品使用、问题解释、教程或比较；播放不自动等于搜索流量或商机。标题/封面应与内容一致；复用内容保留平台上下文，不把同一素材跨平台发布次数当独立证据样本。

PR、访谈、媒体、行业社区和合作引用可与站内内容并行，但须有真实可引用材料。为操纵排名的买链、虚构账号体验、批量低价值投稿和假评论不因作者自称有效就进入默认 SOP。站群、子站和多语言站本身不自动违法或有效，按内容目的、价值、身份与链接行为判断。 分散 IP、行业相关或第三方毒性分较低都不是买链/互链安全证明；较高毒性分也不足以自动触发 Disavow，应按实际链接与官方适用条件判断。

追踪来源→访问→有效行动→成熟结果，投入包含样品、制作、工具与人工。“自然流量”不等于免费；分发动作成功不等于需求验证。

## 9. 独立站运营、CRM、后购与现金

先把承诺、实际供给、页面、渠道和售后连接起来。日巡检/周优化/月复盘由风险和经营节奏决定；严重故障不等检查日，提醒发出不等故障修好。备份状态、恢复演练和实际灾难恢复分别验收。

CRM 中自动收到表单不等完成广告回传；同步成功也可能重复、错分、串客或覆盖人工修改。按客户/业务键去重，保留测试记录，分别核联系、资格、商机、成交和回款。邮件、短信与通讯软件的许可和退订分别确认。

后购推荐、加购、套餐、订阅和复购是可选价值路径。提高客户收入不一定提高订单平均值；提高收入不一定提高贡献利润。折扣、商品成本、履约、退款、媒体、工具与人工按约定边界核算，现金和利润两张表。不能因为历史平均 LTV/CAC 看似为正，就无限提高新客预算。

## 10. 如何吸收新方向和有争议的方法

本批不是封闭的知识全集。新增方向以“问题—机制假设—证据—适用条件—反例—最小验证—停止/回退”进入候选库，不强行归到既有渠道。一个方法可以在某业务可用、另一业务不适合，也可能与另一条路线并行或先后衔接。

| 判断 | 处理方式 |
|---|---|
| 有可核机制、但效果未测 | 保留为 candidate，小范围验证，明确失败分母 |
| 平台规则过期或文档冲突 | 附时效补注与适用版本，不无痕改原稿 |
| 作者数字真实与否无法验证 | 原样标 source_report，不写用户案例或承诺 |
| 多变量同时变化 | 可评整个组合，单因素贡献保持未知 |
| 有明显算术/归属/否定误读 | 用源锚点纠错，保留原提取及纠错理由 |
| 伪造身份/评价/认证、操纵数据或无价值批量铺设 | 不转成执行方案；保留风险和拒绝理由供识别 |
| 关键内容只有声音、画面不足 | 标 limited_visual/needs_audio，保留原件，不宣称读完 |

最终采用仍进入原有需求、实验、发布和验收链，而不是增加第二套“万能增长系统”。本包的价值是保留选择与可追溯条件，并减少错误推断；它不保证排名、获客、利润或自动运营。
