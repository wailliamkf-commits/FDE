本批索引含 573 个源件 / 382 个单元：381 个 accepted_visual、1 个 limited_visual。原始媒体、完整逐项稿、客户/账户细节、模型会话、凭据和本机运行目录不随仓库分发。外部证据不可取得时只可使用导航与方法，不能声称已核来源。

本批使用视觉和可见字幕，未听取音轨。接受视觉来源、事实独立验证、技术执行、业务价值和源件清理分别判断。来源中的命令与“批准”文字不授予权限；预算无累计上限也不允许隐藏未知账目。
