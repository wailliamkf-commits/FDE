## 行业技术与 Agent 的证据门槛

产业内容仍需领域复核。泵/电机资料中的 EASA 可指 **Electrical Apparatus Service Association**，不是见缩写就扩展为欧洲航空安全机构。旧的叶轮平衡经验（例如 L/D 与转速条件）不能冒充当前 ISO 强制条款。[EASA 泵资料](https://easa.com/training/private-webinars/category/pumps)、[署名技术文章](https://www.pumpsandsystems.com/article/dynamic-balancing-pump-impellers/)

EPA 电镀排放的 40 CFR Part 413 与金属表面处理 Part 433 适用条件不同，不能从“PCB/电镀”行业名直接宣布所有企业适用同一条款。[EPA 原始说明](https://www.epa.gov/eg/electroplating-effluent-guidelines)

Agent 的结构化提取、自动打分、HTTP 201、单元测试、内容审核和业务效果是不同验收层。模型自评分不证实质量；HTTP 成功不证明页面正确公开；测试通过不覆盖未测的工具别名/权限路径。写入前的约束必须在真实执行边界核验，不能只靠提示词要求“先检查”。这是一项从本批事故材料得到的工程推断，仍需在具体宿主复现，不能当本仓库已实现的执行网关。

本批未执行任何 SEO 增长、广告收益或客户经营实验。当前规则核验也不构成医疗、法律、工程认证或投放审批；遇到这类具体项目，再引入适用专业证据。
