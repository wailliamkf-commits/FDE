# 交付方案工作表

复制到客户自己的工作区再填写。空字段为未知；本模板不是可执行配置或批准记录。

## 需求与证据

- 需求原话／来源：
- 业务结果、当前基线、统计窗口、样本量：
- 流程：输入 → 当前步骤 → 产出 → 下游使用者：
- 业务Owner／数据Owner／验收人：
- 根因假设／反证办法：
- 已知事实与出处：
- 待确认条件／影响哪项决定／最小验证：
- 范围、非目标、预算上限与期限：

## 技术判断

- 为什么需要AI，哪些部分只需规则、数据或专业工具：
- 可比案例ID、可迁移机制、不可迁移条件：
- 数据敏感级别、允许目的地、保留期限：
- 组件：输入 → 校验/标准化 → 检索/规则/模型/算法 → 人工关口 → 输出：
- 输出契约：格式、字段、来源、下游系统、可编辑性、错误处理：
- 集成预检证据与现有权限：

## A 主方案 / B 备用方案 / C 人工兜底

分别填写每一条路径：

- 适用条件与依赖：
- 实施步骤、角色、交付物：
- 能力范围、时效与质量损失：
- 预计一次性成本、运行成本、维护成本及估算依据：
- 验收与停止条件：
- 从哪条路径切换过来／可观察触发信号：
- 是否改变数据目的地、操作范围或收费／所需新批准：
- 负责人、恢复方式、在途任务与重复执行处理：

## 最小试验

- 最危险且最便宜可验证的假设：
- 合法样本、异常样本、允许执行环境：
- 成功/失败判定与人工对照：
- 本次只交付什么：
- 进入下一阶段所需证据与批准：
