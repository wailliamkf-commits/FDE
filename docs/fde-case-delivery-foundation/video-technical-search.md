# 技术SEO、CMS操作与可验证回退

身份：历史报告中的技术机制经脱敏后形成的工程建议。任何数字、插件能力和平台规则须在项目环境复核；来源证据级别见 [视频证据边界](video-evidence.md)。

<a id="audit"></a>
## audit

来源：012、027、030、035、036、038、039、040、047、050、054、055、064、067、070、075、084、085、089、090、109、110、114。

沿“可抓取→可索引→可理解→可体验”逐层取证：HTTP/robots、meta robots/canonical/sitemap、正文/标题/结构化数据、实际交互/性能。GSC按 Reason×Source×Validation×URL生成问题队列，先判断哪些页面应该索引，索引总数不是目标本身。

先取匿名响应与源码，再读渲染DOM和CMS配置；记录URL、设备、时间、响应、来源环境与缓存状态。Document字节、全部资源体积和传输大小分列；来源054的抓取大小上限主张没有在本包验证，不作为检查器阈值。性能实验室分数和真实用户指标分列；缺实测时写 unknown，不能从静态HTML推算CWV。

H1/H2重复、超长TDK、404高访问、孤儿页、sitemap包含不应索引URL是候选检查。确认意图与模板后再改，不能全站套用分类noindex、Page=Product或自动ALT模板。配置开关、导入进度和API已启用只证明界面状态，验收需保存后重开＋匿名页面＋相关交互。

主路径：只读API/导出＋抓取＋代表页真实交互。备用：人工浏览器抽检高价值路径并列覆盖缺口。人工接管：访问权限、生产配置和法律合规项不清楚；CMP/无障碍清单不等于合规认证。输出问题单采用 [七字段审计](video-architecture-content.md#content)。

<a id="http-change"></a>
## http-change

来源：017、022、027、033、052、055、060、067、068、070、071、078、082、087、095、104、109。

任何301/canonical/noindex/410/删页候选先建表：`source_url / current_status / current_target / proposed_action / exact_target / intent_reason / age / inbound_links / conversions / backup / approval / restore_value`。缺页龄、目标或关键价值数据时只出待核项。

变更前抓源与目标、导出规则、保存内容及链接映射。先小范围验证：源返回预期状态和精确Location，目标200、相关内容可用、无循环/多跳；canonical从页面head读取，确认与实际首选URL一致；内链和sitemap跟随新目标。恢复也要读回响应，不能把“撤销命令执行成功”当恢复完成。

来源087的反例：批量处理自述后出现401、近期内容误重定向；把目的地写成 `DELETE` 仍返回301。需要精确删除/停用对应规则并验源响应，不能用占位文本表达撤销。来源070的数值占位目标也应在校验时拒绝。合并、noindex同样影响业务，并非天然无风险的备用方案。

把假阳性作为单独产物：文章被建议并到列表页、近期内容因暂时零点击被判低质、核心页被越界操作时记录拒绝理由。人工表可只开放“建议动作、是否执行、目标URL、理由”，保持原证据只读；更激进动作重新评估范围和恢复能力。源报告把失败的 `destination=DELETE` 又写入工程主方案，本包明确不采纳该推导。REST取页龄失败可读取先前已授权的HTML/sitemap快照，但日期解析也失败就保留待核，不能用新凭据或高权限登录作为默认绕行。

主路径：获批精确变更＋可恢复快照＋逐URL读回。备用：只调整经授权的文案/内链或输出迁移表，维持原URL。人工接管：401/403、规则身份不明、恢复失败或目标不相关。Disavow只准备现有列表备份、证据及diff；不得从工具毒性分自动生成提交动作。

<a id="media"></a>
## media

来源：025、033、038、081、105、111。

图片批处理先核文件类型、尺寸、EXIF方向、透明度、色彩与输出路径。源文件保留；输出单独目录和映射 `input_hash→output_hash / dimensions / bytes / format / status`，非图像跳过并说明。来源081的案例是等比高度800、Lanczos、WebP质量92；这些为案例参数，不是全站推荐默认值。小图标记需放大决定，避免默认放大造成模糊。旋转校正与保留EXIF是两件事，公开图像还需检查位置等敏感元数据。

来源081还给出可替代的本地探测思路：Windows的System.Drawing不可用时，可评估已安装的Pillow或ffprobe；这不是要求安装新依赖。支持扩展名不等于文件真是图片，应校验解码与实际类型。缩放和有损WebP不能笼统叫无损；对产品细节严格的素材先用小样对比。获取无水印合法原图优先；第三方上传改变数据目的地时须有相应授权。

抽查方向、透明背景、文字可读性、裁切与加载体积；处理数与成功/失败/跳过数一致才算本地批处理完成。081只展示局部输出核对，不能声称整批全部验证，后续上传和首页替换也未完成。

上站另建媒体ID→旧URL→新URL→引用槽位映射，限制精确页面/槽位，备份旧值。通过已授权CMS接口上传后读回媒体，再替换页面、检查src/srcset、ALT含义、桌面/移动渲染及匿名GET的Content-Type。ALT解释图片用途，不从文件名盲填关键词。

主路径：本地转换＋人工视觉抽检＋已授权接口小批上站。备用：输出素材包及映射表供人工上传；API返回405不产生表单登录或REST nonce新权限。只有同样授权且已验证的另一路径才可切换。人工接管：认证失败、引用范围不清、图片200却返回HTML或回滚值缺失。

<a id="cms"></a>
## cms

来源：025、038、039、102、105、108、109。

内容块配置记录 Hook、Taxonomy ID、短代码/块、优先级、语言/设备条件。先试一个分类和分页状态，检查空结果与不相关分类；停用精确块可作为恢复动作。插件升级或页面编辑器迁移先记录版本/依赖/许可，兼容性Unknown进入人工评估，备份及测试站恢复能力要实际验证。

SEO插件迁移（105）：导出原插件设置、title/meta、robots、canonical、Schema、重定向和sitemap样本；保存数据库/文件恢复点；在测试站导入并比较关键页面类型。进度100%、安装成功和设置保存并不证明元数据完整或插件已正确接管。导入 `undefined`、未解释差异或双插件同时输出SEO标记时暂停切换。生产切换后保持单一有效输出源，验证源代码、HTTP与站点地图，旧插件保留可恢复状态；分析连接必须实际授权、选对站点并取得新数据。

历史向导路径为 Getting Started→Import→Your Site→Analytics→Sitemaps→Optimization→Ready；导入对象含Settings、Term Meta、Redirections、Locations、Video Sitemap Settings、Post Meta、Author Meta、Blocks、News Settings。逐类核适用性和前后差异，不因全部勾选就认定无遗漏。角色管理、404/重定向、Schema与Image SEO分别验收；动态ALT/meta可能只在运行时生成，单看数据库不足以验证。安装包名、导入源 `yoast-premium` 和目标插件版本是不同字段；新闻站点地图等条件按当前官方规则确认，不能照抄历史向导。

Schema去重（102）保留为历史工程机制：先检查已有输出，按正文FAQ范围解析问题/答案，避免空壳和重复，解析失败不输出。优先DOM/结构化块，正则对嵌套HTML易误配。正文存在且事实一致是前提。当前搜索展示收益必须另核官方规则，不能为了历史FAQ富结果承诺添加注入脚本。

表单（108）：字段校验/限频、蜜罐、网络风控分层；先观察误拦截，再按真实样本调参，避免照抄邮件域名黑名单或封禁次数。正常访客、移动端、键盘、目标语言各走一条测试提交→后台记录→通知送达。邮件服务故障的备用为受控站内落库＋提示负责人，不能静默丢询盘；记录保存期限按实际目的和要求确定。

主路径：测试站小范围差异核验→获批切换→线上读回。备用：保留原配置，先输出修复清单；无需插件的静态内容可按项目授权使用。人工接管：兼容性、数据丢失、邮件配额、反垃圾误杀、付费功能与权限未确认。

<a id="international"></a>
## international

来源：006、015、020、038、093、104、110、111。

语言白名单应有一个配置来源，CMS与服务器路由读取同一份或做差异核对。测试启用语言、未启用语言、根路径、带路径、尾斜线、真实文件及未知路径；仅当目标语内容不可保留且迁移获批才重定向，不能把所有语言页盲跳首页。临时测试路由仍需防循环与恢复方案。

检查hreflang语言/地区、返回链接、canonical、sitemap及HTML内容语言。翻译字符预算、并发、费用与失败队列分列，界面极大整数不代表无限额度。

图片404（111）先读请求URL、状态及Content-Type，检查翻译层是否改写uploads路径；懒加载排除只是诊断分支。排除媒体路径翻译与媒体改名分开测试，确定真正原因。改名前保存media_id与旧名/旧URL/引用映射，小批更新并检查各语言页面；字符slug化也要防撞名和旧链接丢失。

主路径：已确认目标市场的少量语言＋术语库＋路径/媒体回归。备用：保留已验证语言，其他语言草稿排队。人工接管：内容质量、路由归属、素材命名冲突或旧URL引用不全。视频前后图片恢复有缺帧，不能据此认定具体操作因果。

<a id="fetch"></a>
## fetch

来源：050、094、100、101、114、121。

选择工具按数据需求：单页静态文本可用现有读取；站点清单先map/站点地图再按需抓取；依赖JS的公开内容再用浏览器。批量API适合结构化字段和已获准的规模，但先小样确认schema、失败状态、页数/并发/费用预算和域名范围。

识别登录页、反爬页、空正文和重复模板，避免把错误页面作为内容。每URL保存取得时间、状态、最终URL、正文哈希及方法。重试按仓库上限，失败进入队列。

主路径：已授权且能满足字段契约的接口。备用：同权限公开读取→浏览器人工核对→用户提供合法导出；是否curl或其他工具取决于当前宿主，不照抄视频顺序。人工接管：401/403、需要新增服务商/数据外传/付费或内容访问权不明。降级改变覆盖和时效时明确标记，不能用技术绕行扩展授权。
