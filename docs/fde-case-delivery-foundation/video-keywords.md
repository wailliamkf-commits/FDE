# 关键词研究、意图和页面归属

身份：基于历史视觉报告的工程归纳；证据、版本和隐私约束见 [视频证据边界](video-evidence.md)。精确来源与个别冲突见 [覆盖索引](source-coverage.json)。

<a id="intent"></a>
## intent

来源：005、007、023、034、037、046、049、056、061、069、077、085、086、092、120。

从“谁要做什么决定”开始：采购角色、应用条件、需要比较的参数、预算约束、证据需求和下一动作。将候选词标为了解、排故、比较、选型、采购或导航，再核对实际结果页的主页面类型。若泛词结果由百科占据，不因搜索量大就把它放在商业页首位。

建立记录：`query / locale / country_database / device / source / retrieved_at / intent / existing_urls / proposed_owner / evidence / uncertainty`。语义变体和单位/功率规格先并入一个意图族，只有需求、证据或使用体验明显不同才拆页面。“一个主意图有归属”允许相关页自然包含同词。

词表中的 LSI 应解释为历史工具标签；方法实际要覆盖实体、子问题、关系与自然行业术语。无需设定关键词密度目标。对品牌歧义、成人/影视/跨语噪声只标待核，检查资源是否混站及查询语境，不按字面自动删除。

主路径：客户产品事实＋当前公开SERP＋自有GSC查询交叉判断。备用：无工具订阅时用授权导出、搜索建议、人工抽查的结果页和已有页面；标记日期、地区与样本局限。人工接管：无法确认业务术语或真实意图时交给产品/销售负责人。完成条件为每个候选都有意图、证据和处理建议，不以“导出很多词”完成。

<a id="research"></a>
## research

来源：011—013、024、045、050、057—059、062、065、086、092、094。

1. 冻结种子产品与目标市场，导出自有页面清单。竞争研究先锁定相关子目录，区分 missing 与 untapped，再检查这些缺口是否适合自己的业务。
2. 将原始行和归一化行分开存储，保留工具、国家库、币种、设备、时间、量/KD/CPC定义、是否 simulated。GSC中扩展插件增加的列须注明真正来源。
3. 按意图与页面类型聚类，记录拒绝、合并、保留及失败行。满足 `输入数=已映射+明确排除+待核/失败`；去重另记一对多映射，不悄悄丢行。
4. 用相关性、可提供证据、商业承接和现实竞争共同排序；低权重竞争者能排名是线索，KD/Golden Score/DR不是保证或平台内部权重。
5. 把词簇回填页面地图。先小样核对列义和聚类；工具错误、额度耗尽或导出不完整时落断点，不以摘要总数代替复算。

来源057的输入输出行数不一致是计数反例。来源059/062/092的同词跨工具数值冲突应并列，不能平均后伪造“真实难度”。来源013中评分改善仍存在结构缺陷，说明分数只能辅助审稿。

备用：CSV/表格人工聚类；只能获得一套工具数据时保留单源身份。缺竞争数据可形成条件建议，不能补零或承诺上首页日期。下一步路由：[页面规格](video-architecture-content.md#page-spec)。

<a id="ownership"></a>
## ownership

来源：009、022、029、041、052、053、060、068、071、078、082、087、091、093、095、112。

把 GSC Query×Page 导出按同一资源、搜索类型和日期窗口分组，输出 `query → URL集合 → 每页意图/点击/曝光/均位 → 主要归属候选 → 证据`。多个URL只意味着需要检查：同一查询可以同时需要指南与商业页。

先判断：页面是否承担相同决策，内容是否近重复，排名URL是否稳定，商业入口是否能被找到。可选动作按依赖递增：保留分工→补充内部链接/CTA→改写差异→合并候选→精确迁移。正文相似度只用于找候选，不单独授权删页或跳转。

商业页与指南页可成责任对：商业页给选型、规格、交付边界和询盘；指南回答原理、方法和风险，双向链接有明确上下文。首页→主题/分类→细分文章/产品形成可导航层级；检查孤儿页和断链，自动推荐只生成待审边。

反例：核心词由博客承接时，先补商业CTA与语义清晰的内链；立刻301可能丢掉指南需求。来源087的误重定向证明“零流量”缺少页龄、链接和转化数据时不足以迁移。多站相似度百分比亦非平台处罚门槛。

主路径：完整导出＋正文快照＋内部链接图＋人工确认。备用：只审最高价值的小组页面，缺反链/页龄/转化信息就停在建议。人工接管：目标URL或恢复值未知的迁移。技术实施与验收读取 [HTTP变更与回滚](video-technical-search.md#http-change)。
