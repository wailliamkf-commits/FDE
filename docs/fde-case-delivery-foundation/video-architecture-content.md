# 页面架构、内容生产与本地化

下列为脱敏工程归纳。视频提供了字段、案例和反例，未证明当前站点适用或部署成功；共同约束见 [视频证据边界](video-evidence.md)。

<a id="page-spec"></a>
## page-spec

来源：005、010、014、023、029、032、033、035、037、041、043、044、058、061、066、069、072、076、079、080、085、086、089、099、112、119、120、128。

一张页面规格表连接业务与实施：`page_id / level / parent / proposed_url / existing_url / page_type / audience / intent / primary_query / priority / H1 / H2 / title / description / differentiator / assets / claims / internal_links / CTA / status`。URL、父页、类型、主意图及现有页面冲突先核清；先生成一个可评审页面，避免空数据模板批量铺开。

| 页面任务 | 建议模块 | 验收与反例 |
|---|---|---|
| 首页/主题入口 | 核心定位、分类入口、适用人群、证据、下一步 | 导航能到真实子页；固定字数不是验收条件 |
| 分类/采购中心 | 需求筛选、系列比较、参数矩阵、选型步骤、资料下载、CTA | 每个选型分支有数据来源；型号堆成H2不能替代决策支持 |
| 产品/解决方案 | 应用与不适用条件、规格、配置边界、交付/维护、真实素材、相关产品 | 参数与厂家文件逐项对账；未知产能/认证留待核 |
| 指南/问题页 | 直接回答、步骤、场景、反例、引用、商业页承接 | 不复制商业页主责任；有来源的新增信息才扩页 |
| 替代/对比页 | 为谁选、可比字段、证据、迁移成本、适用/不适用条件 | 榜单自排第一不能替代比较论证；竞品结论有日期和来源 |
| 模型/工具聚合页 | 能力、输入输出、示例、参数、速度/价格口径、对比、使用方式、FAQ | 仅展示真实支持且可核验的模块；空维度不靠模型补满 |

来源119的16模块可归为能力、参数、证据、转化四类；Playground、Examples、API、Benchmarks等需要实际可运行资产。选择少量有用模块优先于机械复制整套目录。来源044的多维配置矩阵应给每轴选项、兼容规则、单位和限制，不将笛卡尔积中的每种组合都假定为可销售方案。

主路径：产品负责人确认事实→内容/设计共享Page Spec→单页预览→桌面和移动交互验收。备用：数据不齐时先发布经批准的说明或下载入口，工具/计算器保留草稿。人工接管：认证、价格、承诺和工程参数由资料负责人签核。计算器须有公式来源、量纲和边界测试，不凭UI展示认定可用。

<a id="content"></a>
## content

来源：007、008、013、017、018、024、026、028、030、041、044、056、064、073、074、075、077、088、097、099、103、106、114、121、124、128。

按意图选择内容结构：Question直接回答后给条件；How-to给前提、步骤和失败恢复；Alternatives按适用人群和取舍；Roundup给入选方法和差异；Vs保持相同字段与证据窗口；Single Review给测试范围、优缺点和不适用人群。Title/Meta反映真实内容；长度、词次、图数和链接数为编辑约束候选，须服从页面用途。

生产顺序：确认读者决策→检查现有页面责任→查来源和反证→列问题与结构→写草稿→补行业知识/原始数据→审稿→人工批准→保存读回。审稿覆盖意图、信息增量、数据真实性、适用边界、术语、逻辑、可读性、链接和商业承接。

声明表最少含 `claim_id / text / source_id_or_url / date / context / unit / jurisdiction_or_scope / confidence / reviewer`。数字和标准号绑定原始资料；标准比较区分地区、设备和应用，未知项写 unknown。自然化之后重新检查数值、逻辑、品牌、链接和限定条件；语言流畅或AI检测分数不能替代事实校验。

审计输出用七字段：`Severity / Title / Evidence / Why / Fix / Example / Validation`。Evidence包含具体页面/片段/取得时间；没有证据的项为待核假设。路线图再加责任人、工作量和验收；不要把未知Prompt正文从目录标题补出来。

主路径：获授权的一手材料＋专家评审＋草稿。备用：公开可信资料的小范围解释稿，缩窄承诺，缺来源的断言撤下或明确待核。人工接管：法律/医疗/工程安全等专业断言及争议事实。内容再加工只使用有权处理的原稿/字幕；链接或口令失效时请求可读材料，不凭标题杜撰视频内容。

发布节奏由可保持的证据质量、审稿能力和承接页决定；记录批次、模型/提示版本和变更日期以便诊断。下降触发停止扩量和调查，不自动证明AI内容受罚或触发删页。

<a id="patch-chain"></a>
## patch-chain

来源：006、015、016、018、020、026、057、064、074、107。

冻结输入版本和页面快照。模型提议的每个补丁绑定 `finding_id / target / old_text / new_text / input_hash / evidence_hash / approval_reference`。确定性应用时要求原文仍匹配；并发变化则该补丁失效，重新审阅。终稿=基线+适用且获批的补丁，不把审稿意见直接当已写入。

保存补丁结果、终稿哈希、读回哈希及失败队列。句子变化只重验相关事实和依赖；页面结构/模板/术语改变需扩大受影响范围。修改后重新读取CMS和实际页面，证实目标版本。已有授权按精确范围执行；哈希和Agent自写审批JSON不产生新授权。

主路径：小批确定性补丁＋读回。备用：输出逐项diff供有权限的人应用。人工接管：原文不匹配、缺回执、审计链中断或语义有争议。批处理数量必须与成功/失败/跳过记录守恒；耗时只说明该阶段，不等于全流程吞吐。

<a id="localization"></a>
## localization

来源：006、015、020、038、093、104、110、111。

按 `preflight→baseline→scan→sweep→terms→apply→review→signoff` 组织本地化。先冻结URL与语言集合，扫描乱码、占位符、语言污染、缺译/残留及未翻标题；术语分固定保留、固定译法、按语境判断，并记录术语库版本。

队列键为 `locale×page_id×segment_id×defect_type`，每片保存输入哈希、修复状态与回执。术语库改变时旧片标 `TERMS_STALE`，只重跑依赖片。母语审核覆盖关键唯一字符串、技术术语、RTL排版和表单提示；抽样得分明确样本范围，不推成全站水平。

主路径：机器硬错清理＋术语归一＋母语复核＋前台读回。备用：保留验证过的语言和少量关键页，停止扩语；翻译额度不足时保存队列而非放大上限。人工接管：目标语义不确定、RTL功能失败或合规表达未核。验收比较URL集合、hreflang互指、页面内容与图片/表单；技术路由见 [国际化](video-technical-search.md#international)。
