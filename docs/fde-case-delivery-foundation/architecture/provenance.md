# 来源、质量与分发边界

本批 61 个视频：54 个 LumaAgent、7 个 AI大模型日记。依据用户交付本地文件的抽样画面文字记录整理；1,842 帧、335 组，约每 10 秒抽样并含末尾帧，无音频转写，不构成完整视频覆盖。

sources.json 只保留原文件标题、SHA256、时长、采样数及身份；未保存可核验的视频 URL，所以不猜测链接。原视频和截图用户已清理，哈希只能识别身份，不能恢复原件。观察文字可能误读，完整分组记录留在用户资料区；仓库只分发提炼的知识、编辑后的通用方案和溯源信息，不上传视频、逐帧全文、账号资料或本机路径。不主张拥有或重新许可作者的原始作品；本包新增模板与工程归纳应与来源作品权利区分，外部分发前另行核查权利。

状态分层：source observation（记录称画面如此）→ candidate reference（编辑的知识和方案）→ local test（某个测试通过）→ host integration（实际环境跑通）→ business acceptance（业务签收）。本次最多到前两层及有限包装/选型测试，不把后几层批量标为完成。

已知纠正：video-001 汇总没有再次直接看图，是分组记录的二次整理。video-060 汇总称 350 秒后无记录，但 group-007 实际记录 360/370/379.433 秒。个别“ASR/OCR”措辞不改变本批没有 ASR 的事实。

## 不转成默认值的主张

- Top50→Top5、8 步、0.6 相似度、500 元、留 5 条快照、3 次失败等为视频示例，不是项目配置。
- RRF 无需调参、向量库按品牌绝对划分能力、必须某一种 PDF 解析路线等没有在此验证。产品版本与真实数据测试决定采用方式。
- 记忆视图过滤不是物理删除；不采用“敏感数据先完整落盘再脱敏”的默认路径。
- 99% 缓存、90%/93% 失败率、薪资承诺不作为效果证据；模型自报置信度不当作校准概率。
- 视频列举的框架、API、模型/缓存能力、评测工具使用前须由项目执行者核对官方版本及必要实测。本次整理不是最新技术调研。

后续纠错保留来源 ID、原主张、替代依据和受影响模式；不静默把来源观点改写成“已验证事实”。
