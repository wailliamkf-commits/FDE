# MM：分层记忆与冲突更新

选用：跨会话事实或偏好确有价值，或任务中间状态需要保留。排除：一次性无状态任务；不要为演示自动建立用户画像。

## 组件与字段

事件输入→必要性/权限检查→结构化抽取→冲突与去重→存储→按用户/时间/任务取回→上下文。
短期（当前对话）、长期（跨会话事实）、工作记忆（中间产物）按用途区分；结构化档案、摘要、滑动窗口按载体区分。精确字段与语义片段分开检索。
编辑建议：subject_id、type、fact、source_ref、valid_from、valid_to、recorded_at、supersedes、sensitivity、retention_policy。有效时间与录入时间分开，处理迟到事件和状态变化。

## 实现与恢复

先列字段与保留目的，再选存储；对话结束抽取、明确事件触发、后台归并是不同写入时机。更新偏好保留冲突来源与适用时间，不把相反事实都当现状。检索可结合语义、时效、重要性和关键词，权重需验证。
压缩保留目标、数字、约束和来源；事实不确定时请用户确认。备用只保存当前任务状态，关闭长期记忆。

测试：用户改口只返回当前有效值；跨用户隔离；迟到事件不覆盖更新事实；同事件不重复写；删除请求覆盖存储/索引/缓存/备份策略而非仅隐藏视图。
