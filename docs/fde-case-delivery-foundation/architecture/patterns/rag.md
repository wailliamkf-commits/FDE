# RG：可定位的 PDF/RAG 知识访问

选用：从已授权资料查找依据。排除：精确实时库存/价格/订单状态应取源系统，不能把旧向量片段当实时事实。

## 两条链

入库：资料分类→解析与版面还原→语义/表格切块→附加元数据→关键词/向量索引。
查询：身份权限过滤→改写/指代消解→多路召回→融合→重排→上下文选择→带引用答案→校验。
原生文本提坐标，扫描件 OCR，混排按数据评估结构识别/视觉路线；完整表格保留行列关系，图片保留说明。组合解析路线可以使用，只要不丢关系与来源。

## 字段与实现

编辑建议：doc_id、version、effective_at、page、section、table_id、chunk_id、acl、source_ref；查询输出 evidence_ids 与 answer_status。
先做少量人工标注问答与页码真值；选择切分策略，建立精确词检索基线，再按错例增加向量、RRF 或重排。父子块可用子块检索、父块提供语境。权限过滤同时约束召回和引用，缓存须按身份/权限隔离。
多跳问题先核验中间实体，再查属性，每跳保留来源；找不到证据则说明不足，不无限扩大召回。

## 故障、备用与测试

正确资料未召回→检索；已召回但未进上下文→排序/裁剪；上下文正确仍答错→生成/指令。无可靠解析时页级人工核验；无索引可使用已批准的精确搜索或小文档人工选择，注明能力损失。
测试：表格数值与页码；旧版本冲突；未授权文档不可召回；缺依据拒答；实时字段改走当前接口；版本更新前后同一测试集回归。
