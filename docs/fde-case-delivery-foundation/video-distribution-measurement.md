# 测量、渠道与GEO的可核验方法

本页为历史资料提炼及工程建议；不带入客户域名、原始询盘、业务数字或效果承诺。来源逐条见 [覆盖索引](source-coverage.json)，证据级别见 [视频证据边界](video-evidence.md)。

<a id="measurement"></a>
## measurement

来源：008、010—012、032、034、042、045、048、049、051、063、076、079、080、083、084、085、088、090—093、095、096、098、103、115、124、131。

报表连接查询→页面→行为→业务结果，每层保留自己的度量。GSC记录点击/曝光/CTR/窗口均位；GA4记录用户/会话/参与和事件；排名供应商记录当前采样名次与覆盖；抓取器说明页面内容；CRM/表单说明有效询盘。不要把API已启用当连接成功，先用代表性资源取得一次真实数据。

统一键至少是 `property / source / metric / dimensions / country / device / window / timezone / retrieved_at`，并保留分子、分母、单位及过滤器。月环比与同比、用户与会话、估算与实测分列。无命中、N/A、过期和零值分别保存，单源失败显示 stale/unknown。跨币种成本账先统一周期、数量、税费和是否重复包含，冲突给差异与待核项。

机会词是待办候选：先有相关曝光，再判断点击不足、承接意图与当前结果页，明确建议落在内容、内链、技术或转化哪一层。每行写证据、责任人、预期改变和验证窗口；没有转化数据时不能推断询盘改善。

掉量诊断先锁资源和时间，再看查询/页面/渠道分布，核对索引状态、发布批次、站点变更、季节性与平台更新。第三方排名分布和GSC不能直接相减。停广告、全AI内容、买外链与曲线变化只是待检验假设；对照或复现缺失时不判定惩罚原因。

主路径：同口径可回溯导出＋页面样本＋真实事件/询盘去重。备用：只展示可取得的指标和数据缺口，用人工确认的询盘分类替代自动归因。人工接管：站点身份不明、计数冲突、窗口未满、样本不足或业务数据未经授权。询盘文本先脱敏再提炼需求类型，原件留在客户项目。

<a id="distribution"></a>
## distribution

来源：019、021、027、031、036、041、066、073、078、082、088、090、113、117、118、127、129、130、132。

外链/数字公关台账含来源URL、目标页、主题相关性、原始可见位置、rel属性、状态、首次/末次见到日期、工具指标来源和授权情况。锚文本可按品牌、裸链、泛锚、主题/标题等归类检查分布；比例和R.T.A加权仅为作者启发，不能成为搜索引擎评分公式。

本包不采用购买传递排名权重、交换链接配额或自动垃圾帖子作为增长方案。合法广告/赞助与操纵排名分开判断：Google将为排名买卖链接、过度交换和自动建链列入链接垃圾，广告/赞助链接应按其要求用 `rel="sponsored"` 或 `rel="nofollow"` 标注。依据为2026-09-21读取的 [Google垃圾政策](https://developers.google.com/search/docs/essentials/spam-policies#link-spam)；其他平台分别核实，人工批准也不消除平台政策约束。

主路径为可引用的真实材料和相关渠道合作：形成候选→验证对方读者与版规→准备有证据的草稿→由有权限的人沟通。抓取失败不等于丢链，至少核HTTP、页面内容和历史快照再判断。学术/媒体域名、DR跃升或群人数不证明可获取性、质量或效果；站点收购需独立尽调，来源132的口述不支持估值。

共享渠道素材登记原始来源、权利、渠道、可复用部分、有效期、事实版本和既往试验。Ads查询/文案可成为SEO候选，公开社交内容可启发选题；直接复制和自动发布不由素材可见性授权。

社区Agent（127/129）先读版规和已有讨论，再草拟适合上下文的内容；风险“存活率”必须说明训练/评估样本和校准，不承诺防封。Campaign的草稿数、已发布数和credits各有台账，不一致暂停启动。账户预热和规避封禁不是本包能力。

备用：只读监测和草稿库，不具备发送/API权限时由人工处理。人工接管：付费链接、商业合作、对外联系、发布或平台处罚风险；相关搜索政策按当前官方规则核对。本包不把换链群名单、客户联系信息或自动投放脚本纳入通用材料。

<a id="geo"></a>
## geo

来源：032、042、096、112、116—120、123、125、126、128、129、133。

分别测量：品牌提及、回答引用、被引用页面、AI来源引荐会话、有效业务事件、传统搜索点击。查询集固定问题/语言/地区/日期/平台和可见模型版本，保留答案片段、引用URL与重复采样规则；一次答案或第三方分数不能替代趋势。不同平台的样本与分数不混成统一曝光量。

实体知识从“是什么、由谁提供、官方入口、能力与限制、证据出处”建立。站点产品/文档/博客及获授权的渠道信息保持事实一致；相互冲突时保留来源和版本，不合成虚构的权威资料。它可以帮助读者和系统理解身份，但不保证被引用或排名。

来源123的Markdown平行页是可读取性候选：若项目确有代理读取需求，确保HTML与Markdown内容/更新同步、权限一致、没有泄露隐藏内容；按路径、UA、Accept、时间、去重口径统计请求。请求量不是唯一用户、答案引用或转化。llms.txt/特殊Schema是否影响某平台必须单独核验，不能从“Agent喜欢Markdown”推导搜索收益。

来源125的引用审计需打开真实来源页核目标链接；筛选词命中页面标题不代表来源平台就是该词。来源126实际报告为GSC Discover；保留它的独立点击/曝光字段，不能命名为Gemini或ChatGPT引用，也不能用少量曝光验证GEO归因。Bing索引、AI引用和Google流量同样是独立层。

主路径：高质量可公开引用的事实材料＋固定问题集采样＋真实来源回访。备用：公开人工抽测，明确平台、重复数和时间局限；没有AI统计时先改善页面可读性，不伪造可见度。人工接管：无引用源、样本极低、平台定义不明或需付费采集。可选试点一次只变一个内容/结构因素，并保留反例与未变化的对照页。

当前官方能力补充与历史视频分开：Google测量先核获授权Search Console生成式AI报表可用性，再用固定问题采样补足。具体口径、缺失值、聚合与属性设置边界见 [三层搜索量化](../../skills/fde-brand-growth/references/search-measurement.md)。这不追认来源126展示过AI专属报表，也不证明其他平台曝光。
