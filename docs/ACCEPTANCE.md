# 本版验收契约

## 正式仓库交付

按 `REPOSITORY_DELIVERY.md` 验证私有仓库身份、完整提交、清单、文件树与检查结果。当前账户安装、商店上架和原生调用不在默认交付范围；不能因其未完成而把已验证的仓库交付标为失败，也不能把仓库交付写成宿主或业务验收通过。

## 可执行验收

1. 无第三方 Python 依赖，doctor 不读取凭据、不请求网络。
2. 标准 Skill metadata、当前插件展示字段与 GitHub workspace marketplace 存在；本地结构校验不等于 Work 管理员导入或宿主认证。
3. 输入不合法、路径越界、未知动作、过期任务输入、停止标记会阻止 scope 预检。
4. 所有远端写入/删除返回 REMOTE_EXECUTOR_REQUIRED；审批模板无法绕过。
5. 证据哈希与验收覆盖缺失时失败；验证文件不夸大为业务或发布通过。
6. 安装器默认预览，使用明确哈希和技能选择；不覆盖旧内容，拒绝 symlink，兼容相同版本幂等。
7. 清理只读且保留被引用/未关闭/过新/跟踪未知/路径可疑的文件；外层仓库、嵌套仓库和 linked worktree 的跟踪项都有真实 Git 回归测试。
8. 首次发布器默认离线预览，限定新私有仓库；真实上传必须在具备 gh 授权的宿主验证。
9. bundle 校验拒绝 manifest 外的额外文件；启发式扫描包含 MANIFEST，但仍不是完整安全审计。
10. 场景、集成、评测/上线和复用模板覆盖 FDE 岗位基线；模板存在不证明真实项目已填写或通过。

## 尚未实现或尚需真实环境验证

生产写入适配器、身份签名审批、一次性授权消费、跨进程锁、多租户隔离、调度服务、系统级急停、自动隔离/删除、签名发布、自动版本升级。

已做文件构建/离线测试 ≠ 已上传 GitHub ≠ 已由 Work 管理员导入 ≠ 已原生安装/调用插件 ≠ 已在真实项目实测 ≠ 已部署运营。
结果报告逐项列状态，不能把未知或模拟试验写成真实通过。
