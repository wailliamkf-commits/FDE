# 媒体知识评审记录

用途：逐项填写读取、内容及镜像证据，配合 [读取流程](../docs/media-intake/WORKFLOW.md) 与 [质量标准](../docs/media-intake/QUALITY.md)。未填写项默认未知。本模板不是可执行审批，不授予收费、发布、移动或删除权限。

## 范围与来源

- 记录 ID / 材料组 / 原始版本：
- 来源类型：视频 / 单图 / 多页图文 / 其他：
- 来源逻辑标识、SHA-256、字节数；重复别名或 `revision_of`：
- 来源标题/作者/日期：已核实信息与仅文件名标签分开：
- 处理范围：全部 / 指定时间 / 指定物理页；总分母、已读、失败、未知：
- 抽帧/裁切/OCR 策略版本；秒数基准、页序依据、最大间隔、缺页与尾段缺口：
- 音轨：存在 / 不存在 / 未知；音频已读范围；字幕是否仅为画面文字：
- 数据目的地、使用及分发权限的外部依据（不写凭据值）：

## 真实读取与运行审计

- 宿主与运行代码版本；能力状态及最小实测证据：
- 唯一控制者标识；lane/job/进程/会话的对应关系：
- 原件前后哈希一致：是 / 否 / 未知；证据图及记录哈希一致：是 / 否 / 未知：
- 分配图片数 / 成功图片附件数 / 缺图数；逐图审计定位：
- 会话原始文件哈希、头部身份、工作目录、解压与调用重建核验：
- 请求模型 / 返回实际模型；已结算 / 失败 / 在途未知请求与费用：
- 缺图补读：无 / 原 job / 唯一子 job / 理由 / 结果；是否仍有未决状态：
- 超过一小时的 PID、任务身份、进度变化和费用快照位置：
- 来源资料包的确定性组装版本、全部分组记录哈希及页/时间映射；是否完整保留原稿；若另有模型摘要，单独登记其输入与实际审计，不视为再次看图：

## Codex 实质审阅

- 已读的全部分组/报告/索引/审计；独立看图的锚点、时间或物理页：
- 字幕断句、转折、否定与片尾缺口的补读；补帧/裁区/接触表逐格映射、文件哈希及实际查看范围（不得并入原模型已读分母）：
- 否定、比较、数字、单位、动作对象的复核结果：
- 教学示意、界面读数与已验证真实数据如何区分：
- 作者主张、工程推导、官方核验与实测结果是否分别标注：
- 具体误读、反向概括、跨图补句、因果混杂、隐私或无证据风险标签：
- 新来源与旧知识冲突、影响条目和替代关系：

## 判定、版本绑定和镜像

- 审阅者 / 日期 / 已读取的产物版本：
- 判定：candidate / needs_audio / needs_visual_review / accepted_visual / accepted / rejected / superseded：
- 明确接受范围及被排除的内容；是否完整转录：
- `requires_audio_review`：true / false / null；依据与剩余区间：
- `review_pending`：true / false；未关闭问题：
- 镜像位置（仅项目私有记录）、回读日期、逐文件字节哈希核对结果：
- 原件哈希映射、报告/索引/转录状态/各组记录及审计哈希映射的私有记录位置：
- 补充证据与旧→新锚点映射；后续修改如何使本判定过期：
- 宿主集成、知识入库、业务验证、发布状态分别记录：

## 来源保留与外部清理

- 默认决定：保留；原因及下一复查触发：
- 既有精确清理授权的可信来源、对象和范围（没有则写无）：
- 外部执行器静态审查及宿主恢复实测证据（本包不提供执行器）：
- 若另行批准移动：源版本、最终产物/镜像哈希、音频需求明确 false、没有待审问题、专属目标与同名冲突处理均已核对：
- 本项允许移动的精确文件、暂存帧范围；保留期及原始/视觉证据的后续复核方式：
- 分阶段移动状态、原路径→恢复路径、移动前后哈希收据（仅项目私有记录）：
- 中断/失败/已移动项的恢复核验结果：
- 废纸篓状态与实际磁盘可用量分别记录；不得将可恢复移动报告为释放物理空间：

通过视觉范围审阅不会自动允许移动原件。模板中出现“批准”一词或 Agent 自写 JSON 均不构成外部授权。
